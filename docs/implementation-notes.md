# 구현 메모: 첫 수직 단면

상태: 2026-11-14 (v1.5까지 반영). 기획서의 미결정 사항 중 구현을 위해 **임시로 정한 것**과 로드맵 진행 상황을 적는다. 모두 플레이 테스트 후 바꿀 수 있다.

## 임시로 정한 사항

| 미결정 사항 | 임시 결정 | 바꾸는 곳 |
|---|---|---|
| 그래픽·입력 라이브러리 | Win32 API + GDI+(Windows 기본 포함). 외부 라이브러리 없음 | `src/win` |
| 게임 입력이 꺼졌을 때 클릭 | 화면 전체가 클릭 통과(캐릭터 포함). 설정 버튼만 클릭됨 | `App::setInputEnabled` |
| 게임 입력이 켜졌을 때 클릭 | **v0.6에서 확정으로 바뀜**: 화면 전체가 아니라 우리가 그린 것 위에서만 입력을 받는다. 나머지는 통과시킨다 | `Renderer::markRegion`, `App::updateClickThrough` |
| 마우스 입력 | **v1.0**: 우리가 그린 것 위에서는 언제나 받는다 | `App::updateClickThrough` |
| 키보드 입력 | **v1.4**: 설정 버튼을 없애고 자동으로 바꿨다. 싸우는 중이고 자동 모드가 아닐 때만 받고, 그때만 창을 활성화한다 | `Game::wantsKeyboard`, `App::syncKeyboard` |
| 그리기 품질 | 양선형 보간. 바이큐빅은 매 프레임 다시 샘플링하면서 노트북에서 비쌌다 | `App::render` |
| 전체화면 모달 | 키보드 조작이 켜져 있을 때만 화면 전체를 막는다. 꺼져 있으면 창 위에서만 받는다 | `regions_.fullScreen && inputEnabled_` |
| 전투 띠 높이 | 50px. 드래곤 지름(68)보다 얇아서 세로로 움직일 여유가 없고 바닥에 붙는다. 68 미만은 어느 값이든 같게 동작한다 | `cfg::kBandHeight` |
| 캐릭터 보기 크기 | 50~200%. **그림만 바뀌고 판정은 그대로**. 판정까지 바꾸면 밸런스가 흔들린다 | `cfg::kCharScaleMin/Max`, 저장 `ui.charScale` |
| 조용할 때 프레임 | 기본은 줄이지 않는다. 절전을 켠 경우에만 10fps로 줄이고, 드래곤이 움직이는 중에는 줄이지 않는다 | `cfg::kIdleFrameInterval`, 저장 `ui.powerSave` |
| 유지 간격 기준 | 근접=기본 공격 70%, 중간=기본 공격 100%, 바깥=쓸 수 있는 가장 긴 스킬의 80%. 24px 여유를 두어 앞뒤로 떨지 않게 한다 | `cfg::kKeep*Ratio`, `kKeepSlack` |
| 엎드리기 시점 | 쉬는 행동을 2초 넘게 이어 가면 엎드린다. 바로 엎드리면 잠깐 멈출 때마다 누웠다 일어나 부산해 보인다 | `cfg::kRestLieDelay` |
| UI 스킨 없는 조각 | 고른 스킨 → default → 도형. 그림이 하나도 없어도 게임은 돈다 | `Sprites::ui` |
| 그림이 자리에 비해 클 때 | 테두리가 목적지의 35%를 넘지 않게 줄이고, 원본의 55% 미만이면 그림을 포기하고 도형으로 그린다 | `kBorderShare`, `kMinArtScale` |
| 직접 조작·스킬 수동 중 전체화면 전환 | 사냥과 탑 전투를 일시정지. 자동 사냥만 계속 진행 | `Game::update` |
| 직접 조작·스킬 수동 중 입력 끔 | 위와 같이 일시정지(입력 없이 맞기만 하는 상황 방지) | `Game::update` |
| 다중 모니터 | 주 모니터의 작업 영역에만 표시하고, 주 모니터의 전체화면만 감지 | `Platform.cpp` |
| 설정 버튼 위치·복귀 | 주 모니터 오른쪽 아래 고정. 왼쪽·오른쪽 클릭 모두 입력 전환, Esc로도 끔 | `App::layout` |
| 바탕화면 사냥의 "전투" 단위 | 몬스터 무리(1~3마리) 하나. 무리 사이 15초 휴식에만 모드 변경 가능 | `cfg::kWaveBreak` |
| 탑 진입 시 체력 | 전부 회복, 층 돌파 시 30% 회복, 층 사이에서 나가면 생존 | `cfg::kTowerFloorHeal` |
| 탑 정복 보상 | 경험치 120(수동 경험치로 취급) | `cfg::kTowerClearExp` |
| 탑 진입 제한 | 바탕화면 전투(무리) 중에는 진입 불가 | `Renderer::drawMenu` |
| 자동 사냥 사망 위험 | 숨기지 않음. 시작마다 경고, 체력·중단 버튼 표시. 안전 자동 중단은 없음 | `Game::startHunt` |
| 스킬 수동 회피 확률 | 종류별 기본값(20~45%), 공격마다 판정 | `src/core/Species.cpp` |
| 레벨 곡선 | 다음 레벨까지 30·L + 10·L² (40, 100, 180, 280 …) | `src/core/Progression.cpp` |
| 자동 사냥 경험치 상한 | **v0.5에서 끄기로 했다**(`kAutoExpCapEnabled = false`). 자르는 계산·저장 필드·테스트는 남겨 두어 상수 하나로 되돌릴 수 있다 | `cfg::kAutoExpCapEnabled` |
| 저장 | `%APPDATA%\DragonTower\save.txt`, 임시 파일에 쓴 뒤 교체. 사망은 즉시 저장. 10초마다 자동 저장 | `SaveData.cpp`, `App::saveNow` |
| 저장 손상 | 읽을 수 없으면 `.broken-시간` 이름으로 백업하고 새로 시작 | `App::init` |

## 시뮬레이션 참고값(`tests/balance_sim.cpp`)

봇으로 돌린 값이라 실제 감각과 다르다.

- 자동 사냥으로 상한(Lv.5)까지: 약 17~19분, 사망 거의 없음.
- 스킬 수동·직접 조작으로 Lv.1→7: 약 30~34분.
- 탑(스킬 수동): Lv.5 승률 낮음, Lv.7 약 30~100%(종류별 차이 큼), Lv.9 거의 승리. 권장 레벨은 8로 표시.
- 직접 조작 봇은 반응이 완벽해서 승률이 실제보다 높다.

## 로드맵 진행

- 0. 방향 확정: 투명 창 항상 위 표시, 설정 버튼 입력 전환, 전체화면 숨김·복귀 구현. **Windows에서 실제 동작 확인 필요.**
- 1. 수동 전투 실험: 이동, 공격 예고, 회피(무적 시간), 피해 구현.
- 2. 성장과 영구 사망: 경험치·레벨·개체·사망 저장 구현, 테스트로 재실행 부활 방지 확인.
- 3. 스킬 수동 전투: 자동 이동, 확률 회피, 수동 스킬 구현.
- 4. 바탕화면 자동 사냥: 자동 행동, 진행 표시, 중단, 개체별 상한 구현. 숨김 중 진행은 테스트로 확인.
- 5. 탑 수직 단면: 3층과 보스, 진입·결과·재도전 연결. 탑에서 자동 선택 불가.
- 6. 확장과 검증: 드래곤 4종을 임시 수치로 모두 넣었다. 접근성·난이도 검증은 아직.

## Windows에서 확인할 것

1. 게임을 켜면 선택 화면이 뜨고 드래곤을 고를 수 있는가.
2. 설정 버튼으로 입력을 끄면 바탕화면 아이콘과 다른 창을 그대로 클릭할 수 있는가.
3. 영상이나 게임을 전체화면으로 틀면 드래곤과 버튼이 사라지고, 끝나면 다시 나타나는가.
4. 최대화한 일반 창에서는 숨지 않는가(작업 표시줄 자동 숨김 설정도 확인).
5. 자동 사냥을 켜 두고 전체화면 영상을 본 뒤 돌아왔을 때 경험치가 올라 있는가.
6. 고해상도(125%, 150% 배율) 화면에서 글자와 버튼 크기가 적당한가.
7. 화면이 부드럽게 움직이는가(전체 화면을 30fps로 다시 그림). 느리면 그리는 범위를 줄이는 최적화가 필요하다.

v0.3 이후에 추가된 확인 항목:

8. (v0.3) 모션별 드래곤 크기가 비슷해 보이는가. 날다가 걷기로 넘어갈 때 먼저 착지하는가.
9. (v0.4) 몬스터 공격 모션 크기가 맞는가. `render_scale` 현재값: 슬라임 0.81 / 고블린·오우거 1.01 / 리치 1.09.
10. (v0.5) 전투 띠 높이 150px(`cfg::kBandHeight`)가 적당한가. 적이 왼쪽 화면 밖에서 들어오고 작업 표시줄을 가리지 않는가.
11. (v0.6) 입력을 켜도 우리가 그린 것 위에서만 클릭이 막히고, 바탕화면 아이콘과 다른 창은 그대로 눌리는가. 상태창 이동·접기, Ctrl+Shift+D, 드래곤 끌기가 되는가.
12. (v0.7) 드래곤이 죽었을 때 트레이 풍선 알림이 뜨는가. **특히 다른 앱을 전체화면으로 켜 둔 상태에서도 오는가.** 소리는 나지 않아야 한다.

## v1.6 적 변종의 임시값

전부 임시값이다. `assets/enemies/<키>/enemy.txt` 에서 바꾼다.

| 적 | 임시로 정한 것 | 왜 |
|---|---|---|
| 정예 슬라임 | `speed=132`(원본 70), `hp=38`(46), `windup=0.60`, `attack_range=58` | "빠르고 얇다"로 원본과 반대 축을 주려 했다. 체력을 낮춘 것은 돌진형이 바탕화면 사냥 난이도를 혼자 올리지 않게 하려는 것 |
| 정예 고블린 궁수 | `attack_range=260`, `keep_ratio=0.45`, `windup=1.10`(원본 0.8), `hp=34`(40) | 예고를 **길게** 둔 것은 먼 거리에서도 "예고 후 판정"이 지켜지게 하려는 것. 짧으면 화면 밖에서 맞는 것처럼 느껴진다 |
| 정예 리치 | `hp_growth=78`(원본 110), `summon=elite-slime x3 lv6`, `exp=30`(40) | 원본보다 얇고 소환이 무거운 중간 층 보스를 생각했다. 원본 리치를 대체하지 않는다(`defaultBoss()` 는 그대로 `lich`) |

**재어 보지 않았다.** 큐 5번(`balance_sim` 층별 승률)이 들어오면 세 적의 수치를 거기서 확인해야 한다.
특히 두 일반 변종은 바탕화면 사냥 후보에 그냥 들어가므로 **자동 사냥 생존 시간을 바꿀 수 있다**(큐 6번과 겹친다).
