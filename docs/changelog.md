# 버전별 바뀐 점

버전은 "밖에서 보이는 변화"를 기준으로 올린다. 저장 파일 형식이 바뀌면 호환 여부를 반드시 적는다.

## v0.2 — 드래곤 폴더와 애니메이션 (2026-11-13)

**드래곤을 코드 수정 없이 추가·수정할 수 있다.** 사용법은 [assets/dragons/README.md](../assets/dragons/README.md).

### 추가

- `assets/dragons/<키>/dragon.txt`로 드래곤의 이름·능력치·스킬·재생 정보를 정한다.
  내장 4종(fire/earth/wind/water)은 적은 값만 덮어쓰고, 새 키는 새 드래곤으로 등록된다.
- 상태별 스프라이트 시트 재생: `idle` `move` `attack` `hit` `death`.
  없는 상태는 `idle`로 대신 그리고, 시트가 아예 없으면 기존 정지 이미지, 그것도 없으면 임시 도형을 쓴다.
- `_example` 폴더: 새 드래곤을 만들 때 복사해 쓰는 템플릿.
- `assets/dragons/template-256.png`: 칸·바닥선·방향 가이드가 그려진 그리기 템플릿.
- `tools/make_sheet.py`: 낱장 프레임이나 다른 규격의 그림을 시트 규격으로 변환한다.
- 데이터 파일과 시트의 문제(모르는 키, 읽을 수 없는 값, 칸 수 불일치)를 게임 시작 시 화면 알림으로 표시한다.

### 바뀜

- 종 목록이 코드의 고정 배열에서 레지스트리로 바뀌었다. 종은 4개를 넘을 수 있다.
  - 코드에서 `kSpeciesCount`는 `speciesCount()`(현재 등록 수)와 `kBuiltinSpeciesCount`(내장 4종)로 나뉘었다.
- 선택 화면은 종 수에 맞춰 카드 너비를 줄이고, 도감은 한 줄에 4종씩 줄바꿈한다.
- 시트가 2칸 이상이면 게임이 위아래로 흔드는 효과를 쓰지 않는다(그림 자체가 움직이므로).

### 저장 파일

- **이전 저장 파일을 그대로 읽는다.** 형식은 바뀌지 않았다.
- 도감(`codex.species`)이 종 번호가 아니라 키 목록으로 다뤄진다. 폴더를 지운 종의 키도 그대로 보관하므로,
  폴더를 다시 넣으면 도감 기록이 되살아난다.
- 저장 파일에 있는 종의 폴더가 사라져도 개체가 다른 종으로 바뀌지 않는다. 그 종은 "데이터 파일이 없는 종"으로 표시된다.

### 아직 안 되는 것

- 스킬 효과 시트(`fx_skill_*.png`), 영혼 안개 같은 레이어 합성, 적·보스의 시트 애니메이션.
- 스킬마다 다른 공격 동작(현재는 모든 스킬이 `attack` 상태를 쓴다).

## v0.1 — 첫 수직 단면
