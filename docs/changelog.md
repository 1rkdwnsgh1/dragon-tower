# 버전별 바뀐 점

버전은 "밖에서 보이는 변화"를 기준으로 올린다. 저장 파일 형식이 바뀌면 호환 여부를 반드시 적는다.

## v0.4 — 몬스터 4종과 적 폴더 구조 (진행 중)

### 추가

- **적도 폴더로 추가·수정한다.** `assets/enemies/<키>/enemy.txt` 로 코드 수정 없이 적을 바꾸거나 더한다.
  드래곤과 같은 형식이고 사용법은 [assets/enemies/README.md](../assets/enemies/README.md)에 있다.
- 적도 상태별 스프라이트 시트를 쓴다(`idle` `move` `attack` `hit` `death`). 대체 규칙도 같다.
- **몬스터 4종**: 슬라임·고블린·오우거(일반)와 리치(보스). 이전 프로젝트 `kospher123-sys/dragon_` 의
  자료를 옮겨 변환했다. 출처는 각 폴더의 `CREDITS.md`에 적었다.
- 바탕화면 사냥에 일반 적이 **무작위로 섞여** 나온다. 탑은 1층 슬라임, 2층 고블린·오우거, 3층 리치다.
- `tools/make_sheet.py` 가 **격자 시트**를 읽는다: `파일.png@행x열:행번호,열범위`.
- 범위를 벗어난 `enemy.txt` 값은 범위로 맞춘 뒤 **경고로 알린다**(전에는 조용히 잘렸다).

### 바뀜

- 임프와 탑의 수호자가 없어졌다. 역할은 고블린과 리치가 대신한다.
  적의 행동(사거리·거리 유지·2페이즈·소환)이 코드 분기에서 **데이터**로 옮겨졌다.
- 도감의 "만난 적"이 고정 2칸에서 등록된 적 전체 목록으로 바뀌었다.

### 저장 파일

- **이전 저장 파일을 그대로 읽는다.** 예전 `codex.imp` `codex.guardian` 기록은 `imp` `guardian` 키로
  옮겨 보관한다(지금은 그 키의 적이 없어 도감에 보이지 않지만 기록은 남는다).
- 적 도감이 키 목록(`codex.enemies`)으로 저장된다.

## v0.3 — 바탕화면 자동 행동 (진행 중)

### 추가

- 사냥하지 않을 때 드래곤이 **쉬기 / 걷기 / 날기**를 스스로 골라 행동한다.
  고르는 확률과 이어 가는 시간, 이동 속도는 `include/core/Config.h`의 `cfg::kIdle...`에서 바꾼다.
  걷기는 화면 아래쪽을 따라 다니고, 날기는 더 빠르게 화면 위쪽까지 올라간다.
- 애니메이션 상태에 **`fly`**가 생겼다. `assets/dragons/<키>/fly.png`를 넣으면 날 때 그 시트를 쓴다.
  없으면 `move.png`, 그것도 없으면 `idle.png`로 그린다.
- 날고 있을 때는 그림자를 작고 옅게 그려 공중에 떠 있는 것을 알린다.
- **걷기는 수평으로만 움직인다.** 날다가 걷기로 넘어갈 때는 먼저 지면으로 내려온다
  (내려오는 동안에도 나는 모습이다). 공중에서 걷는 모습이 나오지 않는다.
- `dragon.txt`의 `[anim.*]`에 **`render_scale`**을 적으면 그 상태만 크게/작게 그린다.
  원본 그림이 상태마다 다른 크기로 그려졌을 때 쓴다. 바닥 기준선은 유지된다.
- 망령룡에 비행 시트(8프레임)를 넣었다.

### 고침

- **`tools/make_sheet.py`가 상태마다 다른 배율을 쓰던 문제.** 각 상태의 윤곽 높이를 저마다 칸의 70%에
  맞추는 바람에, 날개를 펼쳐 윤곽이 긴 비행이 대기의 73% 크기로 작아졌다. `--set`으로 여러 상태를
  한 번에 변환하면 기준 상태로 배율을 한 번 정해 모두에 같은 배율을 쓴다. 망령룡 시트를 다시 변환했다.
- **망령룡의 상태별 몸 크기.** 위 변환을 고친 뒤에도 원본 그림 자체가 비행에서 작게 그려져 있었다
  (흉곽 발광부 높이: 대기 145px, 걷기 128px, 비행 106px). 시트에서 키우면 날개가 잘리므로
  `render_scale`로 그리는 단계에서 맞췄다(걷기 1.13, 비행 1.37).
- `tests/balance_sim.cpp`에서 `printf("%s")`에 `std::string`을 넘기던 문제를 고쳤다.
  v0.2에서 종 이름의 타입이 바뀌며 생긴 것으로, 시뮬레이션 출력이 깨져 보였다.

### 바뀌지 않은 것

- 전투 중에는 자동 행동을 쓰지 않는다. 적이 나타나면 날기를 멈춘다.
- 저장 파일 형식은 그대로다. 자동 행동은 저장하지 않는다(게임을 켤 때마다 새로 고른다).

## v0.2 — 드래곤 폴더와 애니메이션 (2026-11-13)

**드래곤을 코드 수정 없이 추가·수정할 수 있다.** 사용법은 [assets/dragons/README.md](../assets/dragons/README.md).

### 추가

- `assets/dragons/<키>/dragon.txt`로 드래곤의 이름·능력치·스킬·재생 정보를 정한다.
  내장 4종(fire/earth/wind/water)은 적은 값만 덮어쓰고, 새 키는 새 드래곤으로 등록된다.
- 상태별 스프라이트 시트 재생: `idle` `move` `attack` `hit` `death`.
  없는 상태는 `idle`로 대신 그리고, 시트가 아예 없으면 기존 정지 이미지, 그것도 없으면 임시 도형을 쓴다.
- `_example` 폴더: 새 드래곤을 만들 때 복사해 쓰는 템플릿.
- `assets/dragons/template-256.png`: 칸·바닥선·방향 가이드가 그려진 그리기 템플릿.
- `tools/make_sheet.py`: 낱장 프레임이나 다른 규격의 그림을 시트 규격으로 변환한다.
- 데이터 파일과 시트의 문제(모르는 키, 읽을 수 없는 값, 칸 수 불일치)를 게임 시작 시 화면 알림으로 표시한다.

### 바뀜

- 종 목록이 코드의 고정 배열에서 레지스트리로 바뀌었다. 종은 4개를 넘을 수 있다.
  - 코드에서 `kSpeciesCount`는 `speciesCount()`(현재 등록 수)와 `kBuiltinSpeciesCount`(내장 4종)로 나뉘었다.
- 선택 화면은 종 수에 맞춰 카드 너비를 줄이고, 도감은 한 줄에 4종씩 줄바꿈한다.
- 시트가 2칸 이상이면 게임이 위아래로 흔드는 효과를 쓰지 않는다(그림 자체가 움직이므로).

### 저장 파일

- **이전 저장 파일을 그대로 읽는다.** 형식은 바뀌지 않았다.
- 도감(`codex.species`)이 종 번호가 아니라 키 목록으로 다뤄진다. 폴더를 지운 종의 키도 그대로 보관하므로,
  폴더를 다시 넣으면 도감 기록이 되살아난다.
- 저장 파일에 있는 종의 폴더가 사라져도 개체가 다른 종으로 바뀌지 않는다. 그 종은 "데이터 파일이 없는 종"으로 표시된다.

### 아직 안 되는 것

- 스킬 효과 시트(`fx_skill_*.png`), 영혼 안개 같은 레이어 합성, 적·보스의 시트 애니메이션.
- 스킬마다 다른 공격 동작(현재는 모든 스킬이 `attack` 상태를 쓴다).
