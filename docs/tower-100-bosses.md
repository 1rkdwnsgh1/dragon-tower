# 탑 100층 보스 구성안

상태: **확정** (2026-11-16, 사용자 결정). 지역·보스 목록과 패턴 방향이 확정이고, 수치와 패턴 세부는 T4·T7·T8에서 정한다. 그림은 코덱스가 만든다.
상위 설계는 [탑 100층 확장 설계안](tower-100-design.md).

## 개요

탑 100층에는 보스 20마리가 나온다.

- 중간보스 10마리: 5의 배수 층 (5, 15, …, 95층)
- 필드보스 10마리: 10의 배수 층 (10, 20, …, 100층)

필드보스는 드래곤 4마리 파티로만 들어가고, 각 드래곤 레벨이 층×5 이하여야 한다(`core/Tower.h` 규칙).

## 지역 구성

10층마다 지역을 하나씩 두고, 일반 몬스터를 지역마다 두 종씩 배치한다. 보스는 자기 지역의 분위기를 따른다.

| 층 | 지역 | 일반 몬스터 |
|---|---|---|
| 1~9 | 숲 입구 | 슬라임, 고블린 |
| 11~19 | 깊은 숲 | 늑대, 트렌트 |
| 21~29 | 설원 | 설인, 서리 정령 |
| 31~39 | 얼음 성채 | 얼음 골렘, 스켈레톤 |
| 41~49 | 늪지 부족 | 리자드맨, 오크 |
| 51~59 | 물가 신전 | 수룡, 바실리스크 |
| 61~69 | 화산 | 화염 정령, 용암 거인 |
| 71~79 | 망자의 성 | 망령, 데스 나이트 |
| 81~89 | 마수 소굴 | 키메라, 히드라 |
| 91~99 | 심연 | 앞 지역 몬스터를 섞어서 (레벨만 높임) |

남는 **리치**와 **심연 군주**는 보스로 올린다. 자동 사냥은 지금 규칙대로 직전 일반 층의 몬스터를 쓴다(`huntFloorFor`).

## 중간보스

중간보스는 그 지역 몬스터의 우두머리다. 주력 패턴은 하나다. 돌진하면서 소환하는 것처럼 이어지는 행동은 한 묶음으로 본다.

| 층 | 보스 | 주력 패턴 | 예고 방식 | 그림 |
|---|---|---|---|---|
| 5 | 고블린 족장 | 돌진하면서 부하 2마리를 부른다 | 몸을 웅크리는 자세, 돌진 경로 표시 | 새로 |
| 15 | 우두머리 늑대 | 울부짖어 늑대를 부르고 덮친다 | 착지할 자리에 원이 먼저 생긴다 | 새로 |
| 25 | 거대 설인 | 바위를 던진다 | 떨어질 자리에 그림자가 먼저 생긴다 | 새로 |
| 35 | 리치 | 해골을 부르고 마법진을 시간차로 터뜨린다 | 마법진이 깔린 뒤 터진다 | 기존 그림 |
| 45 | 오크 전쟁군주 | 도끼를 휘두르며 돌고, 체력 절반부터 빨라진다 | 도끼를 치켜드는 자세 | 새로 |
| 55 | 늪의 마녀 | 밟으면 느려지는 웅덩이를 깐다 | 웅덩이 자리가 먼저 흐릿하게 보인다 | 새로 |
| 65 | 화산 대장장이 | 망치를 내려쳐 충격파를 세 줄로 보낸다 | 망치를 들어 올리고 줄 표시 | 새로 |
| 75 | 흑기사 단장 | 잔상을 남기고 순간이동해서 벤다 | 나타날 자리에 잔상이 먼저 생긴다 | 새로 |
| 85 | 바실리스크 여왕 | 부채꼴 모양으로 광선을 쏜다 | 눈이 빛나고 부채꼴 범위 표시 | 새로 |
| 95 | 심연의 문지기 | 차원문을 열어 이전 지역 몬스터를 부른다 | 차원문이 열리는 동안 소환 예고 | 새로 |

5층 고블린 족장 자리에는 기존 오우거 그림을 임시로 쓸 수도 있다.

## 필드보스

필드보스는 파티 4마리가 모두 필요하도록 만든다. 조작하는 1마리 말고 자동으로 싸우는 3마리도 맡을 일이 있도록, 여러 곳을 동시에 상대하거나 흩어져야 하는 패턴을 넣었다.

**입장할 때만 4마리가 필요하고, 끝까지 4마리가 살아 있어야 하는 건 아니다.** 한 마리가 죽어도 남은 파티로 공략할 수 있어야 한다.

| 층 | 보스 | 4마리가 필요한 이유 | 그림 |
|---|---|---|---|
| 10 | 슬라임 왕 | 맞으면 작은 슬라임으로 갈라져 나눠 처리해야 한다 | 새로 + 작은 슬라임(기존 슬라임 그림 재사용) |
| 20 | 고대 세계수 | 약점 열매 4개를 모두 깨야 재생이 멈춘다. 순서대로 깨도 되지만, 첫 열매를 깬 뒤 제한 시간(임시 15초) 안에 다 깨지 못하면 다시 자란다 | 새로 + 열매 부품 별도 |
| 30 | 서리 여왕 | 얼음 기둥으로 전장을 갈라 파티가 흩어진다 | 새로 |
| 40 | 본 드래곤 | 뼈 비를 맵 전체에 뿌려 각자 피해야 한다 | 새로 |
| 50 | 거대 히드라 | 머리 3개가 따로 체력을 가지고, 하나만 자르면 다시 자란다 | 새로(일반 히드라보다 크게) + 머리 3개 부품 별도 |
| 60 | 리바이어던 | 촉수 4개와 본체를 동시에 상대한다 | 새로 + 촉수 부품 별도 |
| 70 | 화산 군주 | 아래쪽에서 용암이 올라와 위로 피해야 한다(탑 전투 화면에서만 쓰고, 좁은 바탕화면 띠에서는 쓰지 않는다) | 새로 |
| 80 | 망자의 왕 | 저주 표식이 붙은 드래곤은 다른 드래곤과 떨어져야 한다 | 새로 |
| 90 | 키메라 군주 | 사자 돌진, 염소 마법, 뱀 독 패턴이 번갈아 나온다 | 새로(일반 키메라보다 크게) |
| 100 | 심연 군주 | 3페이즈. 이전 필드보스 패턴을 섞어 쓴다 | 새로(크게, 기존 그림은 참고용) |

자동 드래곤 3마리가 예고 범위를 피하는 행동은 T7(파티)에서 만들어야 한다. 그게 없으면 30·40·80층처럼 흩어져야 하는 보스에서 자동 드래곤이 죽기 쉽다.

## 공통 설계 원칙

저장소 규칙에서 나온 원칙이다. 모든 보스가 지켜야 한다.

- **모든 공격은 예고 후 판정**: 범위, 그림자, 자세 같은 예고가 먼저 보이고 그다음에 맞는다. 예고 없는 즉사 공격은 넣지 않는다.
- **원소 상성 없음**: 원소는 삭제했다. 얼음과 불은 외형에만 쓰고, 약점 계산은 하지 않는다.
- **영구 사망 유지**: 보스전에서 죽은 드래곤도 되살아나지 않는다. 그래서 패턴은 어렵더라도 읽을 수 있어야 한다.
- **소리 없음**: 예고는 화면 표시로만 한다.
- **물약은 탑 전용**: 한 번 오를 때 최대 2개라서 보스 난이도도 이걸 기준으로 맞춘다.

## 코덱스 그림 요청 규격

이번 일반 몬스터와 같은 형식으로 받으면 같은 변환 도구를 그대로 쓸 수 있다.

| 항목 | 요청 내용 | 이유 |
|---|---|---|
| 배치 | 12열 × 5행, 위에서부터 대기 / 이동 / 공격 / 피격 / 사망 | 일반 몬스터와 같은 형식 |
| 해상도 | 칸 하나 512px (12열×5행이면 한 장 6144×2560px) | 이전 생성본은 1942×809px이라, 같은 방식으로 요청만 해서는 이 규격이 보장되지 않는다 |
| 방향 | 오른쪽을 보는 그림 | 게임 시트 기준과 같다 |
| 배경 | 투명 PNG | 오버레이로 바탕화면 위에 그려진다 |
| 칸 경계 | 그림이 옆 칸으로 넘치지 않게 | 넘치면 잘라낼 때 조각이 섞인다 |
| 공격 줄 | 앞쪽 3~4프레임은 힘을 모으는 예고 자세 | 예고 후 판정 규칙을 그림으로도 보여 준다 |
| 크기 관계 | 보스는 칸을 크게 채우되, 무기·날개·공격 자세까지 포함해 가장자리에 여백을 두기 | 크게 그리되 잘리지 않게 |

만들 그림은 **본체 19종**이다(중간보스 신규 9종 + 필드보스 신규 10종). 리치는 기존 그림을 다시 쓴다.

여기에 따로 움직이는 부품이 더해진다: 세계수 열매, 히드라 머리, 리바이어던 촉수. 개별로 공격하고 부수려면 본체와 따로 그려야 한다. 스킬 효과 그림도 필요할 수 있다.

패턴의 예고 표시(원, 그림자, 부채꼴)는 게임이 직접 그린다. 부품을 엔진에서 어떻게 지원할지는 T4에서 정한다.

**제작 순서**: 한 보스로 먼저 제작, 크기, 분할, 게임 안 재생까지 검증한 뒤 나머지로 넓힌다. 첫 보스는 부품이 없는 5층 고블린 족장이다. 부품이 있는 보스(세계수·히드라·리바이어던)는 부품 규격을 정한 뒤에 만든다.
