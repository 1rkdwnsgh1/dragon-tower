# 망령룡 스킬 기획 V1

저주 중첩 PR 1은 [확정 규칙](../game-design.md#확정-망령룡-저주-중첩-2026-11-19)을 따른다. 영혼 자원은 아래 PR 2 규칙을 따른다. 궁극기 충전 및 소비 시점은 [PR 3 확정 규칙](../game-design.md#확정-망령룡-궁극기-충전-2026-11-19)을 따른다. 죽음의 행렬은 아래 구현 검수값을 따르며, 저주 응용·소모는 후속 설계 대상이다.

## PR 2 — 영혼 수확

영혼 수확이 해제된 망령룡은 확정된 적 처치마다 영혼 1개를 얻으며 최대 10개를 보유한다. 최대 체력 6% 회복과 기존 회복 효과는 유지한다. 체력이 가득 찼을 때도 영혼을 얻고, 영혼이 가득 찼을 때도 체력이 부족하면 회복한다.

영혼은 현재 드래곤의 런타임 자원이다. 사냥 시작·종료, 탑 도전 시작·정복·퇴장, 드래곤 교체·사망, 게임 재실행에서 초기화한다. 같은 탑 도전의 층 이동은 영혼을 유지한다. 상태창에는 보유량을, 획득 시에는 `영혼 +1`을 표시한다.

상태: **콘셉트 제안 / 기술 설계 대기 / 구현 미승인 / 밸런스 미확정**. 기록일: 2026-11-13.

출처: 사용자가 제공한 `REVENANT_SKILL_GITHUB_WORK_HANDOFF.zip` 안의 `REVENANT_DRAGON_SKILL_PLAN_V1.md` 전체와 `WORK_GITHUB_PUSH_PROMPT.md`. 기존 [캐릭터 기획](revenant-dragon.md)을 보완하는 스킬 상세의 단일 기준 문서다. 시각 콘셉트 후보 60종의 목록과 선호 기록은 [추가 스킬 시각 기획](revenant-dragon-skill-concepts.md)에 따로 있고, 그 60종은 이 문서의 스킬 구성과 아직 대응되지 않았다. 이번 반영은 문서만 추가·수정하며 코드·게임 데이터·이미지·개발 우선순위는 변경하지 않는다.

## 1. 전투 정체성과 적용 경계

고대의 저주받은 해골 군주라는 외형에 **저주 축적 + 영혼 수확 + 망령 소환**의 혼합 전투 정체성을 제안한다. 기본 공격은 원거리 망령탄을 우선하고, 근접한 적에게 망자의 발톱으로 대응한다. 복잡한 필수 수동 콤보를 요구하지 않고 자동 전투·방치 플레이의 흐름을 유지하며, 적합한 액티브는 플레이어가 자발적으로 발동할 수 있는 방향이다.

이는 [통합 기획서의 전투 모드](../game-design.md#4-전투-모드)를 대체하지 않는다. 자동 사냥은 바탕화면에서만 가능하며 탑에서는 금지한다. 기존 직접 조작·스킬 수동·자동 사냥 모드는 유지하고, 자동/수동 병행의 구체 범위는 기술 설계에서 검토한다. 영혼 수확은 적 처치에 관한 후보 기능이며 사망한 드래곤 개체의 부활이나 영구 사망 예외가 아니다.

상아색·회백색 골격, 청록 흉부 코어와 눈, 비대칭 손상 영혼 날개, 분절된 창 끝 꼬리와 의식용 사슬을 유지한다. 제거된 검은 깃발은 다시 넣지 않는다. 스킬마다 영구 외형을 바꾸지 않는다.

## 3. 세부 연출과 효과 제안

### 망령탄·망자의 발톱

망령탄은 턱을 조금 열어 작은 청록 영혼탄을 응축하고 발사한다. 탄 안에서 고통받는 혼령의 얼굴이 잠깐 보이며 명중 시 영혼 증기가 적에게 스며든다. 기본 피해와 저주 확률·중첩은 후보다. 적이 인접하면 짧고 힘 있는 발톱 휘두르기와 얇은 영혼 참격으로 대응한다. 자주 사용하는 기본 공격이므로 과도한 동작은 피한다.

### 혼령 관통

안개를 흉강 안으로 끌어들이고 코어가 번쩍이며 가늘고 긴 영혼 창을 응축해 적 하나를 관통한다. 피격 대상에 청록 영혼 균열이 잠깐 드러난다. 높은 단일 피해와 저주 대상 추가 피해를 제안한다.

### 망령의 침식

자세를 낮추고 흉곽을 미세하게 열어 짙은 저주 안개를 전장 바닥으로 흘린다. 안개 속 망령의 손이 적을 붙드는 연출을 한다. 범위 지속 피해와 저주 부여가 후보이며, 손의 시각 표현이 실제 속박 기능 확정을 뜻하지 않는다. 검수·승인된 환경 안개의 질감은 참고할 수 있지만, 단순 확대 대신 **퍼져 나가는 별도의 공격 애니메이션**이 필요하다. 기존 안개 패키지가 모두 승인되었다고 간주하지 않는다.

### 영혼 수확

체력이 부족할 때 기존 회복 효과를 표시한다. 적 처치 인정과 자원 수치는 위 PR 2 규칙을 따른다. 흉부 코어의 자원 연출과 강화 효과는 후속 제안이다.

### 망계의 숨결

1. 충전: 눈·코어 발광이 강해지고 주변 안개가 열린 턱으로 빨려 들어가 목 안쪽을 밝힌다.
2. 방출: 뒤틀린 혼령 얼굴들이 실린 거대한 청록 영혼 격류가 수평 전방으로 쏟아진다.
3. 잔류: 공격이 지나간 자리에 반투명 영혼 안개가 잠깐 남는다.

통합 개선에서 재사용 대기시간을 14초에서 25초로 올렸다. 기존 `bonestorm` 준비 0.48초 후 2.5초 동안 전방에 0.25초 간격으로 최대 10틱을 적용한다. 마지막 틱 뒤 잔류 효과를 포함해 약 3.46초 동안 기존의 이동·입력 잠금을 유지한다. 최대 피해는 방어 적용 전 공격력 15.6배(틱당 1.56배)로 통합 개선의 7.8배에서 두 배로 높였다. 저주 폭발은 첫 유효 틱에서 소비한 중첩당 해당 틱 피해를 20% 높인다. 틱마다 일반 적에게 0.25초 동안 이동 제한을 갱신한다. 동레벨은 제자리에 고정하고, 하위 레벨은 레벨 차에 따라 12~30px 뒤로 민 뒤 접근을 막는다. 상위 레벨은 레벨 차에 따라 이동 속도가 35~75%로 줄어든다. 보스는 기존 밀림 면역을 유지하며 화면 진입 중인 적은 강제로 밀지 않는다.

### 죽음의 행렬

멈춰 서서 날개를 장엄하게 펼치고 저장된 영혼을 방출한다. 뒤편에서 망령 군세가 형성되어 전장으로 돌진하고 마지막에 영혼 폭발과 포효하는 자세로 절정을 만든다. 수확한 영혼을 사용하는 다수 대상 궁극기를 제안한다. 머리 위 영혼 왕관은 **일시적인 궁극기 효과**이며 영구 뿔 구조를 바꾸지 않는다. 포효는 시각 연출이며 소리는 추가하지 않는다.

### 죽음의 행렬 구현 검수값

2026-11-21 충돌 폭발만 `assets/references/revenant-dragon/procession-impact-v1/`의 원본으로 교체했다. 원본의 512×512 셀 12장을 256×256 가로 시트로 변환했으며 중앙 (128, 128)을 군세별 충돌 좌표에 맞춘다. 기존 0.44초 단발 창에서 모두 재생하며 최대 불투명도를 68%로 제한한다. ZIP의 프레임당 70ms 제안은 참고용이다.

발동·소비 규칙은 [통합 기획서](../game-design.md#확정-죽음의-행렬-발동-규칙-2026-11-19)를 따른다. 검수용 임시값은 Lv.8 해제, 첫 충돌 후 재사용 30초, 폭발 반경 110, 군세당 공격력 11.69배다. 같은 적이 세 번 모두 맞으면 방어 적용 전 공격력 35.07배로, 기존 시전 총합 5.01배의 7배다. 첫 발사 1.40초, 나머지는 0.4초 간격이다. 속도는 620px/초, 충돌 잔류는 1.04초다. 화면 전체를 추적할 수 있도록 최대 비행 시간은 전장 대각선과 출발 오프셋을 이동하는 시간에 2초를 더한다. 대상이 없으면 발사 후 최대 2초까지 0.10초 간격으로 재탐색한다.
`dragon.txt`의 `procession_shots`, `procession_interval`, `procession_speed`, `procession_lifetime`에서 조정한다. 현재 발사는 3회다. 향후 궁극기 Lv.1~5의 3~7회는 성장 설계 후 이 발사 수에 연결할 수 있다.

복구 팩의 두 manifest에서 프레임 순서·레이어·길이를 읽었다. 본체와 효과 7종은 각각 8프레임의 256×256 정사각 셀 가로 시트로 변환했다. 원본 왼쪽 방향을 게임의 오른쪽 기준으로 뒤집고, 본체는 공통 배율과 수평 중심으로 y=240에 맞췄다. 기존 공격 시트는 그대로 사용한다.

| 레이어 | 위치 및 시작 |
|---|---|
| ritual | 시전자 발밑, 0초 |
| soul_eruption | 시전자 흉부 부근, 0.48초 |
| spectral_crown | 시전자 머리 위, 0.70초 |
| army_emergence | 각 군세의 발사 위치에서 시작해 추적 이동과 함께 나타남 |
| spirit_charge | 유도 중인 군세의 실제 위치와 좌우 진행 방향 |
| final_impact | 각 군세가 충돌한 시점과 위치 |
| aftermath | 각 군세의 충돌 위치에 남아 감쇠 |

군세는 시각 레이어이며 독립 AI는 없다. 원본 README의 색 테두리, 흐린 배경, 잔광 클리핑과 본체 프레임 외형 변화는 실제 확인 항목으로 유지한다.

## 4. 시너지 후보

망령탄 / 망령의 침식 → 저주 축적 → 혼령 관통의 추가 피해 또는 망계의 숨결의 저주 폭발 → 처치 시 영혼 수확 → 축적 영혼으로 죽음의 행렬.

전체 연결은 제안이다. 저주 상태·중첩, 자원, 처치 귀속, 범위 대상 선정, 소환의 실체와 수동 개입을 검토해야 하며 필수 수동 콤보로 확정하지 않는다.

## 5. 애니메이션·에셋 정책

- 캐릭터 동작과 스킬/VFX를 분리한다. 입을 여는 숨결 자세와 실제 영혼 격류, 환경 안개를 한 장에 영구 합성하지 않는다.
- 투명 RGBA PNG, 일정한 칸 배치와 재현 가능한 시트를 사용하고 타이밍·루프를 별도 검수한다. 캐릭터용 규격은 [캐릭터 적용 기획](../character-pipeline.md#4-확정-스프라이트-시트-규격), 효과용 세부 규격은 해당 문서의 미확정 사항을 따른다.
- 첨부 기획의 왼쪽 지상 마스터·반쯤 열린 손상 날개는 **원본 참고 방향**이다. 게임 납품 방향은 기존 확정대로 오른쪽이며, 망령룡 원본은 `--mirror` 변환과 좌우 반전을 허용한다. 손상 날개의 신체 기준 좌우 보존을 다시 요구하지 않는다.
- WALK·FLY·IDLE 제작/적용 경과는 [제작 기록](revenant-dragon-progress.md)과 [변경 기록](../changelog.md)을 구분해 참조한다. 환경 안개는 IDLE·WALK·FLY별 움직임에 맞추는 방향이며 FLY용 안개 제작 완료를 뜻하지 않는다.
- `REVENANT_SOUL_MIST_WALK_V1`은 생성만 완료한 검수·수정 대기 자료다. 이를 승인된 공격 효과로 재사용하지 않는다.
- 실제 표시 크기에서 공격과 위험이 읽혀야 한다. 골격·뿔·코어·날개 손상이 프레임마다 달라지지 않게 검수한다. 공격 상태·시각 단계·프레임 수·명중 프레임은 전투 인터페이스 검토 후 정한다.

| 스킬 슬롯 | `SkillDef skills[3]`, 입력 1~3, 종별 `[skill.1~3]` | 기본 공격 2종·패시브·액티브 4종을 현재 3슬롯에 직접 대응시킬 수 없음. 장착/확장 여부 미정 |
| 기존 망령룡 임시 스킬 | 영혼 탄(Projectile), 저주의 안개(Zone), 망령의 포효(Burst) | 새 V1로 개명·교체하지 않음. 후보와 기존 임시 데이터의 대응은 기술 설계 대기 |
| 단일·범위·직선 피해 | 기존 SkillKind에 Projectile·Zone·Line 등 8종 존재 | 기본 피해 형태 참고 가능. 저주 중첩·폭발·영혼 자원·수확·소환은 기존 이름/수치 변경만으로 구현 불가 |
| 자동·수동 | 자동 사냥에서 AI 스킬, 직접 조작/스킬 수동에서 입력 스킬 사용 | 자동 중 수동 개입·우선순위·궁극기 트리거는 미확정. 기존 모드와 탑 제한을 유지 |
| 동작·효과 | 공통 attack 상태 사용. 스킬 효과 시트와 안개 레이어 합성은 미구현 | 스킬별 자세, 충전/방출/잔류, 독립 VFX와 소환은 팀 기술 검토 필요 |
| 방향·음향 | 오른쪽 시트·반전 허용, 소리 없음 | 첨부의 왼쪽은 원본에만 적용. 음향 설계는 미결정 목록에서 제외하고 기존 무음 결정을 유지 |

새 스킬 동작은 [캐릭터 적용 기획 5장](../character-pipeline.md#5-확정-스킬-적용-방식)에 따라 팀이 함께 검토한다. 소환 군세가 실제 전투 개체인지 시각 효과인지, 자원·상태의 저장 여부도 현재 구현으로 보장하지 않는다.

## 7. 작업 순서 — 대기 제안

[개발 로드맵](../roadmap.md)의 단계·체크포인트와 현재 진행 중인 v0.3을 그대로 유지한다. Windows 실제 확인, 기존 애니메이션 검수·에셋 통합 및 미해결 품질 항목의 완료를 이번 문서 업로드로 선언하지 않는다. 첨부의 제작 순서를 즉시 시작하면 기존 미완료 작업보다 앞서게 되므로 **실행 일정으로 채택하지 않는다**. 우선순위 변경에는 별도 승인이 필요하다.

선행 작업 완료 또는 명시적인 일정 재승인 후 검토할 순서:

1. 기존 로드맵·전투 인터페이스·명명 규격을 재확인한다.
2. 기본 공격, 저주, 영혼 자원·처치 수확, 범위 피해, 근접 전환, 수동 개입·궁극기 지원 범위를 확인한다.
3. 대상 선정·타이밍·발동 규칙과 슬롯 대응을 결정한다.
4. 제작 복잡도 기준 후보 순서: 망령탄·망자의 발톱 → 혼령 관통 → 영혼 수확 → 망령의 침식 → 망계의 숨결 → 죽음의 행렬.
5. 캐릭터 동작과 독립 효과를 실제 렌더러·상태 전환에 맞춰 검증하고, 앞선 마일스톤 완료/재승인 후 로드맵에 편입한다.

## 8. 미확정 사항

- 피해량·재사용 대기시간·습득 레벨·저주 확률·중첩 상한·지속 시간·영혼 자원 상한과 밸런스.
- 근접 거리 기준과 발톱이 원거리 기본 공격을 대체하는지 추가하는지.
- 슬롯·장착 방식, 자동 발동 우선순위·동시 쿨다운·수동 개입 UX, 모드별 허용 범위.
- 저주의 중첩 계산과 숨결의 소모·폭발 규칙, 단일/광역 대상 판정.
- 영혼 수확의 처치 인정·회복/강화 계산, 궁극기 자동/수동 발동과 소환 방식.
- 공격 프레임 수·판정 프레임·단계 시간·좌표·효과 시트 규격·합성 계층·상태 전환·중단 처리.
- 기술 설계·팀 검토·게임 적용 승인과 착수 시점. 본 문서는 구현이나 에셋 제작의 승인이 아니다.


## 망계의 업화 구현 검수값

`skill.9`는 기존 `Zone`에 전용 시전 경로를 추가한다. Lv.9 해제 후 장착 키 또는 자동 전투로 시전한다. 임시값은 탐색 거리 490px, 충돌 반경 115px(보기 크기 연동), 초당 공격력 1.65배(방어 적용 전), 장판 4.5초, 재사용 22초다. 별도 브레스 피해는 주지 않는다.

수동 스킬 조작 중 적이 없어도 발동한다. 자동 전투는 기존 탐색 거리 안에 적이 있어야 발동한다. 시전 당시 방향으로 수평 이동하고 입에서 하향 벡터를 뻗어 발 높이와의 교차점을 구한다. 전장 밖에는 충돌과 장판을 만들지 않는다.

V3 검수값은 도약 0.85초에서 0.27초, 비행과 분사 0.8초에서 2.0초다. 비행 속도는 기존 이동 속도의 0.8배를 유지하므로 경계에 막히지 않는 이동 거리는 2.5배다. 준비·도약 20칸을 유지하고 분사 자세 10칸은 10 FPS로 반복한다. 착지 10칸과 1초는 유지한다. 브레스는 하향 55°와 기존 입 기준점을 유지하고, 중심축에 수직인 폭만 0.44에서 1.32로 늘린다.

V5 충돌은 브레스가 지면에 닿는 동안 같은 중심점과 시전 시간을 사용해 20 FPS로 반복한다. 지면 불꽃은 첫 접촉과 이후 이동 34px마다 생성한 위치에 유지한다. 경계에 막혀 이동을 멈추면 같은 지점에 장판이 반복 생성되지 않는다. 같은 시전에서 겹치는 장판의 피해율은 한 번만 적용한다.

지속 불꽃 시트의 기준 높이는 본체 칸의 9.5%에서 22%로 높였다. 기본 대기 시트의 256px 칸에서 발 기준선과 아래쪽 가슴 사이를 약 40~47px로 보고, 가장 높은 불꽃의 알파 경계와 최대 크기 편차를 반영했다. 기본 화면 크기에서 가장 큰 불꽃은 발 기준점 위 약 19px을 목표로 한다. 충돌 효과 높이는 피해 반경의 1.55배를 유지한다. 모든 배율은 검수용이며 피해 반경은 그대로 사용한다.

V4는 저장된 `ui.charScale`의 100%를 기준으로 삼는다. 도약 0.27초, 비행·분사 2초, 착지 1초, 장판 4.5초는 유지한다. 비행 이동에만 크기 배율을 곱해 같은 시간에 더 길거나 짧게 이동한다. 100%에서는 V3와 동일하고 50%·150%에서는 이동 거리, 입과 지면 사이의 브레스 벡터, 자동 탐색 거리, 장판 반경이 각각 0.5배·1.5배다. 반경 115px은 기존 `skillRadius`에서 한 번만 스케일하고 적과의 접촉 여유는 기존 규칙을 따른다.

첫 접촉과 이동 `34px × 크기 배율`마다 장판을 남긴다. 장판당 불꽃은 6개에서 15개(2.5배)로 늘리고, V3의 시트 높이 22%를 유지한다. A~F 6개 원본을 인스턴스마다 재사용하고 시작 시간·위치·성장과 소멸 주기는 별도로 정한다. 불꽃 개수를 바꿔도 초당 피해와 같은 시전의 장판 중첩 규칙은 유지된다. 전투 중 크기를 바꾸면 이후 비행과 접촉에 새 배율을 쓰고 이미 놓인 장판은 생성 당시 크기·위치·수명을 유지한다.

본체 40칸은 원본 10 FPS 자료이며, 대각선 브레스 합성본 16칸과 V5 충돌 1~12칸은 20 FPS다. 지속 화염 A~F는 GROUND·REAR·FRONT를 각각 128px 가로 시트로 변환한다. 원본의 홀수 프레임을 사용하고 세 패스의 발 기준점을 일치시켰다. 생성 위치·크기·지연·주기는 불꽃마다 따로 정한다. E는 원본과 같이 1회만 재생한다. V5의 13~72번과 LINGERING V1의 합성 잔류는 독립 화염과 중복되므로 적용하지 않았다.
