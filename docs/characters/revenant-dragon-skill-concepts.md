# 망령룡 추가 스킬 시각 기획 (60종 콘셉트 목록)

상태: **시각 콘셉트 탐색 자료 / 제작 승인 아님 / 스킬 확정 아님 / 구현·밸런스 미승인.** 기록일: 2026-11-16.

7차에 걸쳐 만든 1컷 콘셉트 시트 **이미지 7장**과 **생성 프롬프트 원문 7개**를 보관하고, 각 시트에 담긴
**기술 콘셉트 60종**과 사용자의 시각 선호 기록을 정리한다.

이 문서는 콘셉트 **목록과 선호 기록**만 담는다. 스킬의 전투 정체성·분류·발동 방식은
[망령룡 스킬 기획 V1](revenant-dragon-skills-v1.md)이 기준이고, 외형 기준은
[캐릭터 기획](revenant-dragon.md)이 기준이다. 여기서 중복해 적지 않는다.

## 자료 위치

원본은 [작업 자료 폴더](../../assets/references/revenant-dragon/work-2026-11-16-skill-planning/)에 있다.
PNG는 Git LFS로 관리하므로 받을 때 `git lfs pull`이 필요하다.

| 자료 | 파일 |
|---|---|
| 콘셉트 시트 이미지 7장 | `스킬 추가 기획 1컷 이미지 1.png` ~ `7.png` |
| 생성 프롬프트 원문 7개 | `스킬 추가 기획 1컷 이미지 1 프롬프트.txt` ~ `7 프롬프트.txt` |
| 파일별 크기·SHA-256·화소 해시·ZIP 사본 비교 | `manifest.json` |
| 기계 판독용 60종 목록 | `SKILL_INVENTORY.csv` |

출처는 사용자 PC의 `드래곤 타워/gpt 작업용 레퍼런스/망령용/스킬 추가 기획` 폴더와, 사용자가 전달한
`DRAGON_TOWER_REVENANT_CLAUDE_HANDOFF.zip` 인계 묶음이다. 보관 시 확인한 사항은 아래 "보관 검증"에 적는다.

## 이미지 공통 기준

프롬프트 7개가 공통으로 요구한 조건이다. 외형 기준 자체는 [캐릭터 기획](revenant-dragon.md)을 따르고,
여기서는 **시트 생성 조건**만 적는다.

- 고정 측면 2D 전투 화면 구도. 드래곤은 **항상 왼쪽**, 작은 적 실루엣은 오른쪽. 세트 안에서 드래곤 크기와 카메라 배율을 같게 유지.
- 어두운 폐허 석조 전장, 청회색 구름, 원경 고딕 폐허. 청록·연청 네크로맨시 발광.
- 손으로 그린 듯한 2D 판타지 일러스트. 3D·사진 사실주의·원근 카메라·HUD·로고·워터마크 금지.
- 효과는 패널 경계를 넘지 않고, 각 패널 아래에 작은 영문 스킬명 라벨만 둔다.
- 한 세트 안의 패널은 서로 뚜렷하게 다른 연출이어야 한다.

## 현재 자료의 한계

- **1컷 콘셉트 시트다.** 투명 배경의 게임용 에셋도, 연속 재생 가능한 애니메이션 프레임도 아니다.
  실제 적용에는 [캐릭터 적용 기획](../character-pipeline.md)의 스프라이트 시트 규격에 맞춘 별도 제작이 필요하다.
- 영문 라벨은 **가칭**이다. 현재 `assets/dragons/revenant/dragon.txt`의 스킬 키와 대응하지 않는다.
- 60종은 후보 풀이며, 현행 **액티브 4칸 장착**([확정: 스킬 해제와 장착](../game-design.md))에 비해 훨씬 많다.
  어느 것을 몇 개 넣을지는 정해지지 않았다.
- 5~7차는 개별 선호 선택 전이므로, 이 중에서 제작 후보를 추리는 일이 다음에 사람이 정할 자리다.

## 보관 검증 (2026-11-16)

- PC 원본 14개(이미지 7 + 프롬프트 7)를 모두 가져왔고, 보관본의 SHA-256이 **14개 전부 원본과 일치**한다.
- PC 원본 14개는 **확장자가 없었다.** 내용은 그대로 두고 이미지에 `.png`, 프롬프트에 `.txt`만 붙였다. 그 외 이름은 원본과 같다.
- **인계 ZIP의 이미지 6장은 1~6차의 재인코딩 사본이다.** 화소는 완전히 같지만 바이트와 용량이 다르다
  (예: 1차 ZIP 3,454,267바이트 / PC 원본 2,700,341바이트). ZIP의 "재압축하지 않았다"는 설명과 어긋난다.
  보관본은 **PC 원본**을 채택하고 ZIP 사본은 넣지 않았다. 비교 결과는 `manifest.json`의 `zip_handoff_comparison`에 남겼다.
- **7차 이미지는 실재한다.** 인계 ZIP과 그 인덱스는 7차를 "이미지 미제작, 프롬프트만 존재"로 적었으나,
  PC 폴더에 `스킬 추가 기획 1컷 이미지 7`(PNG 1774×887, 2,927,830바이트)이 있었다. 따라서 이미지는 6장이 아니라 **7장**이다.
- 7개 프롬프트의 패널 순서가 위 목록의 기술 순서와 **모두 일치**한다. 합계 60종으로 맞는다.
- 누락 없음. 폴더에 다른 파일이나 하위 폴더는 없었다.
