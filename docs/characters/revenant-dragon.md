# 망령룡 (Revenant Dragon) 캐릭터 기획

상태: 외형 기준 확정 · 2D 제작 우선 · 스킬 및 게임 편입 미확정. 기록일: 2026-11-12.

## 1. 콘셉트와 결정 범위

고대의 죽음의 군주를 연상시키는 해골형 드래곤. 자연스럽게 풍화된 골격 안에 청록색 영혼 에너지가 흐르고, 왕관형 뿔과 손상된 영혼 날개로 위엄과 오랜 세월을 드러낸다. 구체적인 세계관 사건이나 전투 역할은 아직 정하지 않았다.

최신 모델링용 컨셉 시트를 공식 외형 기준으로 삼는다. 실제 제작은 **2D 게임 캐릭터 일러스트와 에셋을 우선**한다. 컨셉 시트라는 이름이 3D 제작 확정을 뜻하지 않는다. 기존 화염·대지·바람·물 4종 중 무엇을 대체할지, 추가 종인지, 플레이어용인지 보스용인지도 미정이다. [통합 기획서](../game-design.md)의 전투·성장·영구 사망 규칙은 그대로 적용한다. 언데드 설정은 사망 개체의 부활 기능을 의미하지 않는다.

### 유지할 외형

- **골격:** 실제 척추동물처럼 유기적인 굴곡과 자연스러운 관절 연결. 흉곽·척추·사지의 주요 뼈는 이전보다 두껍고 묵직하게 보이되, 우아하고 날렵한 전체 비율을 유지한다. 금속 갑옷이나 조각품처럼 매끈한 뼈는 피한다.
- **재질:** 오래된 상아색·회백색. 미세한 균열, 침식과 요철로 세월을 표현한다. 과도한 부패나 지저분한 좀비 표현은 지양한다.
- **영혼 코어:** 흉곽 중앙의 빛나는 청록색 코어가 핵심 식별 요소다. 눈·입·갈비뼈 내부와 날개로 이어지는 영혼 에너지를 유지한다.
- **날개:** 뼈 프레임과 반투명 영혼 막의 조합. 한쪽이 더 손상된 비대칭을 유지한다. 손상된 쪽의 신체 기준 좌우와 찢김 위치는 제작 전 시트 대조 후 고정해야 하며 이 문서에서 임의 지정하지 않는다.
- **머리와 장식:** 고대 파충류의 두개골 같은 머리, 왕관처럼 솟은 뿔. 사슬·룬 장식은 골격과 코어를 가리지 않는 보조 요소로 둔다. 뿔의 개수와 장식 연결 위치는 뷰별 검수 대상이다.

초기에는 체형 확대를 시험했으나 최종 기준은 최신 풍화 골격 시트다. 이전 수정 프롬프트의 뼈 두께 약 10~15% 증가는 생성 지침이며 제작 치수나 추가 확대 명령으로 취급하지 않는다.

## 3. 2D 일러스트와 게임 에셋 방향

완성 일러스트에서는 최초 배경 이미지의 낮은 시점, 크게 펼친 날개, 폐허·거대한 건축물과의 크기 대비, 청록 혼불과 저주 기운으로 군주의 압도감을 살린다. 외형과 골격은 최신 시트를 따른다.

게임용 이미지는 배경을 분리한 투명 PNG로 제작하고, [기존 에셋 규격](../../assets/README.md)을 따른다. 현재 게임은 오른쪽을 보는 정지 이미지 한 장을 좌우 반전해 표시한다. 망령룡용 파일명·종류 ID·로딩 연결은 아직 추가하지 않았다. 기존 종 이미지를 덮어쓰지 않는다.

기존 드래곤 표시 높이 약 102px에서도 왕관 뿔, 흉부 코어, 손상된 날개의 차이가 읽히도록 축소 검수한다. 사슬과 균열은 필요 시 단순화하되 핵심 실루엣을 유지한다. 영혼 오라가 몸 윤곽이나 공격 예고를 가리지 않는지도 확인한다. 현재 공통 생성 예시의 귀여운 아기 드래곤 비율은 망령룡의 확정 외형에 그대로 적용하지 않는다.

### 향후 애니메이션 제작 제안 — 미구현·미확정

- 골격 본체, 앞뒤 날개, 영혼 막, 코어·눈 발광, 사슬과 효과를 분리할지 검토한다.
- 대기·이동·공격·피격·사망 상태를 후보로 두고 필요한 동작부터 정한다. 프레임 수, 속도, 시트 배치와 구현 방식은 별도 결정한다.
- 프레임마다 관절 위치, 코어 중심, 접지점, 캔버스 크기와 기준점을 맞춰 흔들림·잘림을 검사한다.
- 비대칭 날개는 단순 좌우 반전 시 신체 기준 손상 위치가 바뀐다. 양방향 전용 에셋 또는 반전 허용 여부를 결정하고 검증한다.

## 4. 스킬 — 후보 단계

앞선 대화에서 제안된 스킬은 모두 **후보이며 최종 채택되지 않았다**. 이번에 조회한 대화 기록에는 기존 후보의 정확한 이름과 효과가 포함되어 있지 않아 임의로 복원하거나 새 후보를 확정 목록처럼 기록하지 않는다. 원문을 확보하면 출처와 함께 후보 목록을 보완한다.

스킬 이름, 개수, 효과, 피해량, 재사용 대기시간, 습득 레벨, 전투 역할은 모두 미확정이다. 청록 영혼·저주 이미지는 시각 테마이며 흡혈·소환·부활 등의 실제 기능을 확정한 것이 아니다. 현재 코드에 있는 다른 종의 스킬은 망령룡의 확정 스킬로 간주하지 않는다.

## 5. 제작 및 일치 검증 체크리스트

AI 생성 시트는 외형 기준으로 사용하되 정면·측면·후면의 구조가 모두 일치한다고 가정하지 않는다. 2D 에셋·애니메이션 제작 전 검수하고, 향후 3D 모델링을 진행한다면 모델링 착수 전 정투상 자료를 보완한다.

- [ ] 정면·측면·후면의 머리·목·흉곽·골반·사지·꼬리 비율과 높이 일치
- [ ] 뿔의 개수·분기·위치, 턱과 치열, 척추 돌기 대응 확인
- [ ] 날개 뿌리·관절·손가락 뼈 연결과 펼침/접힘 구조 확인
- [ ] 신체 기준 손상 날개의 좌우, 막의 찢김과 결손 위치 고정
- [ ] 흉부 코어의 위치·크기, 갈비뼈와 장식 연결 위치 일치
- [ ] 관절 가동 시 골격·날개·사슬 간 겹침과 관통 검수
- [ ] 2D 축소 표시·투명 경계·양방향 표시와 애니메이션 프레임 일관성 검수
- [ ] 불일치 부위는 승인된 기준 그림으로 수정하고 수정 이력 기록

다음 작업은 기준 시트 검수 → 2D 측면 시안 → 실제 표시 크기 확인 → 필요한 애니메이션 범위 결정 순으로 제안한다. 이는 아트 준비 순서이며 [개발 로드맵](../roadmap.md)의 단계 완료나 다음 단계 진행 승인을 대신하지 않는다.
