- 변환된 24개 셀이 원본 공통 변환 결과와 바이트 단위로 일치함을 검사했다. [24칸 정적 대조표](../../assets/references/revenant-dragon/fly24-2026-11-19/contact.png)에서 방향·주요 외곽과 자세 순서를 확인했다. 기존 비행 키 자세가 유지되지만 중간 날개가 늘어나거나 흐려지는 부분은 최종 품질 승인이 아니다.

## 2026-11-19 — WALK24 게임용 시트 적용

상태: **PR #96 main 병합 완료 / 이미지 QA NEEDS_REVIEW / Windows 실제 재생 미검증**. 기존 개발 순서를 변경하거나 다른 확인 항목의 완료를 선언하지 않는다.

- 입력: `DRAGON_TOWER_WORK_WALK24_HANDOFF.zip`의 **24_FRAME_COMPAT_REPLACE_18**. `source/frames/REVENANT_WALK_01.png`~`24.png`를 파일명 순서로 사용했고 **18번은 17.5 보조 자세 교체본**이다. 25프레임이나 원본 6×4 시트를 런타임으로 사용하지 않았다.
- 보존: [원본 ZIP·이전 이동 시트·QA 자료](../../assets/references/revenant-dragon/walk24-2026-11-19/README.txt). 원본 24장의 SHA-256·RGBA·1024×1024·파일 순서를 `SOURCE_MANIFEST.json`과 대조해 통과했다. 이전 `move.png`와 설정은 기준 커밋으로도 복구할 수 있다.
- 변환: `tools/make_sheet.py <해제한 source/frames> -o assets/dragons/revenant/move.png --mirror --align union --cell 256`. 기본 `--ratio 0.70`, 배경 제거 없음. 공통 윤곽 상자와 같은 배율·좌표로 반전·리사이즈하여 상대 움직임을 유지했다. 프레임별 재정렬·재생성 없음.
- 다른 상태를 재변환하면 기존 모션 픽셀이 달라지므로 이번에는 move만 변환하고 IDLE/기존 MOVE와 비교했다. 오른쪽 지향 **6144×256 RGBA, 256×256 가로 24칸**, 공통 기준점 **(128,240)**. 반전 후 공통 상자 `(53,168,969,828)` → `249×179`, 배치 `(4,61)`이다. 기준점 정렬은 각 프레임의 모든 발이 땅에 닿는다는 보장이 아니다.
- `dragon.txt`의 실제 설정 **fps=8, frame_w=256, loop=yes, render_scale=1.13**을 유지했다(주석만 갱신). 1프레임 125ms, 전체 3초이며 이전 8프레임 1초 루프보다 길다. 보행 속도·이동 거리의 적합성은 실제 재생 후 판단한다.
- 정적 대조표에서 오른쪽 방향, 코어·골격·날개·꼬리의 식별, 외곽과 바닥선, 17·18·19 및 24·01, 120px 축소 표시를 확인했다. 큰 끝부분 잘림은 관찰되지 않았으나 네 다리의 해부학·하중·접지와 루프의 자연스러움을 승인한 것은 아니다.
- 전체 윤곽 기준 그려지는 높이는 기존 MOVE 약 75% → 새 MOVE 약 79%, IDLE 약 70%다. 자동 검사의 10%p 범위 안이나 같은 신체 부위의 크기 일치나 전환의 자연스러움을 뜻하지 않는다. 정적 비교에서 새 모션이 조금 크게 보여 기존 보정값의 적절성은 재생 검수에 남긴다.

전용 본체와 대각선 브레스, V5 충돌 12칸, 독립 지속 화염 A~F의 3개 패스를 게임에 연결했다. 첨부 원본 ZIP은 보존했다. 리뷰용 본체와 각 효과는 프레임 구조·크기·투명도를 확인했다. 상세 이미지 품질 승인은 별도이며, 실제 게임 성능과 레이어 가림은 [Windows 체크리스트](../windows-checklist.md#망계의-업화)에 남겼다.

Windows x64 Release 빌드와 CTest 8종을 통과했다. 신규 자동 검사는 해제, 수동·자동 발동, 지정 충돌, 피해, 장판 공존, 시전 취소와 전투 종료 정리를 포함한다. Windows 미리보기는 좌우와 50%·100%·300%·1000%에서 총 29장 캡처했다.

### 망계의 업화 V2

무대상 수동 발동과 전진 비행을 연결했다. 원본 도약 프레임은 유지하고 준비 시간을 줄였다. Windows x64 Release 빌드와 CTest 8종을 통과했고, Windows 미리보기에서 좌우 및 네 가지 배율의 64장 캡처를 생성했다. 100% 미리보기에서 도약, 입에 붙어 이동하는 브레스, 세 차례 V5 충돌, 착지 후 남는 작은 불꽃을 확인했다. 실제 전투에서 적 가림, 화면 경계와 동시 출력 성능은 [Windows 체크리스트](../windows-checklist.md#망계의-업화)에서 확인한다.

### 망계의 업화 V3

도약을 줄이고 비행 속도를 유지한 채 이동 거리를 2.5배로 늘렸다. V5 충돌은 브레스 접촉점의 단일 반복 이펙트로 옮겼고 지속 불꽃은 경로에 고정한다. 브레스 단면과 잔류 불꽃 배율을 조정했다. Windows x64 Release 빌드와 CTest 8종을 통과했다. Windows 미리보기에서 좌우 및 비행 중 접촉점 이동과 착지 후 잔류를 확인했다. 실제 게임 전투에서 가림과 성능은 [Windows 체크리스트](../windows-checklist.md#망계의-업화)에 남겼다.

### 망계의 업화 V4

장판당 독립 불꽃을 6개에서 15개로 늘렸다. 먼저 켜지는 불꽃과 지연 후 피어나는 불꽃을 섞었다. 불꽃 배치에 쓰는 난수는 전투 판정 난수와 분리하고, 기존 6종 시트와 프레임 캐시를 재사용한다. 크기 50%·100%·150%에서 비행 거리, 브레스 벡터, 자동 탐색 경계와 장판 피해 반경을 자동 테스트로 확인했다. 기본 크기의 V3 피해율과 겹치는 장판의 중복 방지 규칙을 유지했다. Windows 미리보기의 좌우 재생을 확인했으며, 적과 이펙트가 동시에 많이 표시될 때의 실제 게임 프레임 시간은 별도 검수 대상으로 남겼다.

### 망계의 업화 V5

대기 시트와 전용 시트의 흉곽·목·골반을 맞춰 전용 본체를 1.26배로 보정했다. 바닥선과 좌우 위치를 정렬했고, 브레스의 입 좌표에 같은 보정을 적용했다. Windows x64 Release 빌드와 CTest 8종을 통과했다. Windows 미리보기에서 50%·100%·150% 좌우와 대기·걷기·시전·착지·복귀의 단계별 캡처를 확인했다. 실제 게임의 조작 전환과 시전 중 크기 슬라이더 변경은 [Windows 체크리스트](../windows-checklist.md#망계의-업화)에 남겼다.

### 망계의 업화 V5 도약·착지 타이밍

도약과 착지를 독립 설정으로 두고 각각 0.4초로 맞췄다. 원본 도약 20칸과 착지 10칸을 각각 50 FPS와 25 FPS로 재생한다. Windows x64 Release와 CTest 8종을 통과했다. Windows 미리보기의 연속 프레임에서 도약 20개와 착지 10개 자세를 확인했다. 실제 전투 중 입력 복귀는 Windows 체크리스트에 남겼다.

### 망계의 업화 V5 시각 개선

V5 타이밍 커밋을 기준으로 기존 본체 40칸과 브레스·충돌·독립 화염 시트를 재사용했다.
도약은 웅크린 자세를 짧게 잡고 빠르게 펴며, 공중 날갯짓은 내리치는 구간을 앞당겼다.
착지 후 자세가 회복되기 전에 발이 지면에 닿고, 착지점에 재 파편이 퍼진다.
브레스 시작점은 공격 시트의 턱 안쪽에 맞췄고 밝은 불티가 입에서 지면으로 흘러간다.
지면에 불이 옮겨붙을 때 섬광과 파편을 띄우고, 낮은 불꽃 사이에 크기와 점화 시점이 다른 불꽃을 섞었다.

시전 타이밍(도약 0.4초, 비행·분사 2초, 착지 0.4초), 비행 거리, 피해 영역 및 피해율은 V5 값을 사용한다.
입 앵커 미세 보정은 화면에 그리는 브레스에만 적용한다. 접촉점과 장판 배치 판정은 V5 계산을 사용한다.

Windows x64 Release 빌드, CTest 8종, 망령룡 기본 시트 9종 검사를 통과했다.
Windows 미리보기에서 전체 시전과 잔불 소멸을 캡처하고 50%·100%·150% 좌우의 입과 지면 접촉점을 확인했다.
재검수에서 왼쪽 충돌 시트를 반전하고 앵커 오프셋도 함께 반전했다.
실제 전투 조작, 적과 효과의 가림, 전투 중 프레임 시간은 Windows 체크리스트에서 확인한다.

### 망계의 업화 V5 지속 화염 연결

V5 polish 미리보기에서 착지 후 높은 불꽃 사이로 바닥이 끊겨 보였다. 기존 D형 화염의 바닥 레이어를 지면 앵커에 맞춰 넓게 깔고, 각 장판의 점화 시점과 남은 수명에 맞춰 밝기를 조절했다. 장판 반경과 생성 시 불꽃 높이를 사용해 작은 캐릭터에서도 연결부가 함께 줄어든다.

이번 수정은 망계의 업화 바닥 렌더링에만 적용한다. 본체 배율, 시전 시간, 비행 거리, 피해 범위와 피해율은 V5 polish 값을 사용한다.

Windows x64 Release 빌드와 CTest 8종을 통과했다. Windows 미리보기로 50%·100%·150% 크기의 좌우 시전에서 수정 전후 60쌍을 비교했다. 대기와 도약 확인 프레임은 일치했고, 이후 차이는 지면 주변의 낮은 잔불에 집중됐다. 50%에서는 연결부 차이가 작다. 실제 전투 조작, 적과의 겹침, 동시 출력 시 프레임 시간은 미검증이다.

## 망계의 업화 V6 비행 불꽃

GitHub 작업 브랜치와 동일한 `fbd2eba` 위의 로컬 V5 Ground Continuity를 기준으로 삼았다. 미커밋 Cinematic의 본체 잔상, 흉부 압축 발광, 추가 브레스 리본, 충격파·섬광, 밝아진 지면 띠와 추가 잔불을 걷어냈다. 기존 브레스 불티, 충돌 시트 추적, 지면 연결 띠, 장판별 독립 화염은 V5 기준을 따른다.

- 도약 0.4초 동안 흉부에서 먼저 점화한다. 도약 후반에는 날갯짓에 맞춰 등과 날개 가장자리 쪽으로 불꽃이 뻗는다.
- 전진 비행·하향 분사 2초 동안 후면 화염은 날개 끝과 몸통을 감싸고, 얇은 전면 화염은 흉곽 아래와 턱의 브레스 시작점을 연결한다.
- 착지 0.4초 동안 몸에 붙은 불꽃의 길이와 불투명도를 줄인다. 독립 지면 화염은 각 장판의 남은 수명으로 계속 재생한다.
- 새 투명 RGBA 시트는 `fx_soulfire_wrap_rear.png`, `fx_soulfire_wrap_front.png`다. 각각 256px 칸 40개이며 `python tools/make_soulfire_wrap.py`로 재생성한다. 렌더러는 기존 본체의 위치·방향·크기·모션 프레임을 두 시트에 그대로 사용한다. 스킬 데이터와 전투 판정은 V5 기준을 따른다.

첫 미리보기에서 작은 흉부 점화를 키우고 날개 끝의 직선적인 불꽃을 곡선으로 다듬었다. V5 지면 띠의 폭·높이·불투명도를 복원한 뒤, 신규 시트를 제외한 렌더를 V5 실행 파일과 대조했다. 50%·100%·150%, 좌우, 밝고 어두운 배경의 단계별 캡처 156쌍이 픽셀 단위로 일치했다. 최종 V6 캡처는 같은 156조건에서 몸체 불꽃의 노출과 착지 이후 동일한 지면 화염을 확인했다. 25 FPS 전체 GIF와 V5/V6 주요 프레임 비교를 별도로 저장했다. Windows x64 Release, CTest 8종, 망령룡 본체 시트 9종, 신규 RGBA 시트 2종 검사를 통과했다.
