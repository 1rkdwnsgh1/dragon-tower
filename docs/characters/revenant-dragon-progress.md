### 게임 적용 및 검수

기준 커밋 `23736cb`, 기존 브랜치 `docs/awakened-bone-shot-archive`, [PR #121](https://github.com/1rkdwnsgh1/dragon-tower/pull/121). 현재 등록된 캐릭터에 각성 화석룡 전용 종이 없어 기존 망령룡에 일반 액티브 `skill.11`로 추가했다. 기존 슬롯 인덱스는 유지된다. 레벨 11에 해제되며 빈 칸 자동 채움과 수동 장착은 기존 규칙을 따른다. 자동은 AI가 장착 기술로 사용하고, 스킬 수동과 직접 조작은 장착 칸 입력을 사용한다. 가까운 대상이 없으면 발동하지 않으며 직접 조작에서 발사 전 회피는 기존 시전 취소 규칙을 따른다. 임시 수치는 피해 계수 3.2, 대기시간 12초, 사거리 520px, 비행 속도 572px/s다.

### 실플레이 피드백 반영

골각 사출 F07에서 각성하면 전투 종료·대기 전환 뒤에도 계속 유지한다. 수동 전투에서 적이 없을 때 사용하면 즉시 각성한다. 각성 중 같은 장착 칸을 다시 누르면 해제한다. 자동 전투는 각성을 발동할 수 있고, 이미 각성 중이면 이 칸을 건너뛴다. 개체별 상태는 저장 후 다시 열거나 개체를 전환해도 복원한다. 기존 저장은 일반 모습으로 시작한다.

각성 본체는 이전 시전 시트 표시 높이의 2.25배를 사용한다. 발 기준 (128, 240)을 보존한다. 대기 12칸(3 FPS), 이동 24칸(7.5 FPS), 기본 공격 24칸(24 FPS)은 기존 각성 제작본의 게임용 시트를 사용한다. 전용 레이어가 있는 숨결·망령익참·망계의 업화·궁극기는 해당 시전 연출을 재생한 뒤 각성 모습으로 돌아온다. 배율은 골각 사출 이마 발사 좌표에 연동한다. [Windows 좌우·크기 대조표](../../assets/references/revenant-dragon/awakened-bone-shot-2026-11-23/awakening-size-contact.jpg)에서 발사 뒤 1.5초에도 각성 본체가 남는 것을 확인했다. Windows Release와 CTest 8개, 골각 사출 전용 검사 51개가 통과했다.

### 각성 중 기본 공격

각성 중 자동 기본 공격은 가장 가까운 적 쪽으로 골각 사출을 반복한다. F07에서 발사하며 기본 공격의 피해 계수와 0.9초 공격 간격을 쓴다. 대상 조준과 비행 거리에 수치 상한을 두지 않고 화면 경계에서만 소멸한다. 같은 투사체는 적마다 한 번 피해를 주며 기존 접촉 효과를 재생한다. 최초 각성 사출은 스킬의 피해와 사거리를 사용한다. 기본 공격 준비 중에도 각성 해제 키가 동작한다. 이동 표적 대응을 위해 기본 골각 사출의 속도를 572에서 1040px/s로 높였다. 최초 각성 사출은 572px/s를 유지한다. 좌우 150% 프리뷰에서 16FPS 간격으로 본체와 두 표적 사이의 비행을 확인했고, 자동 테스트는 진로를 가로지르는 이동 표적의 명중을 확인했다. 실플레이 후속 피드백에 따라 각성 기본탄을 1040에서 2080px/s로 높였고, 추가 조정 후 3500px/s로 적용했다. 근접 피드백을 반영해 기본탄은 시전 때 선택한 적의 현재 위치를 첫 명중까지 따라간다. 조준한 적이 이마 안쪽에 있으면 몸 중심에서 발사한다. 맞히거나 대상을 잃으면 마지막 비행 방향으로 직진한다. 좌우 근접 표적이 시전 중과 발사 뒤에 움직이는 경우, 피해 1회 및 명중 후 직진을 자동 테스트로 확인했다.

- 입력 `REVENANT_FLY24_FROM_APPROVED_KEYS_V1.zip`: 승인된 비행 키 8장 + 광학 흐름 중간 16장. **24장 모두 1024×1024 RGBA·투명도·파일명 순서·6×4 원본 시트 셀 대응**을 확인했다. 잠금 키 01·04·07·10·13·16·19·22의 픽셀이 동봉 `QA/APPROVED_SOURCE_SHEET.png`의 8셀과 일치한다.
- [원본·백업·QA 보관 폴더](../../assets/references/revenant-dragon/fly24-2026-11-19/README.txt)에 ZIP을 바이트 그대로 보관하고 이전 `fly.png`도 `fly-before-8frames.png`로 보존했다. SHA-256과 변환 수치는 `validation.json`에 있다.
- `tools/make_sheet.py <frames> -o assets/dragons/revenant/fly.png --mirror --align union --cell 256 --ratio 0.90`. 기존 fly의 약 90% 칸 높이 기준을 유지했다. 공통 상자 `(78,40,906,985)` → `202×230`, 배치 `(27,10)`. 같은 배율·위치로 오른쪽 지향 **6144×256 RGBA 가로 24칸**을 만들었다. 프레임 재생성·개별 재정렬 없음. 다른 상태를 다시 변환하지 않아 기존 WALK24·IDLE 등은 보존했다.
- 기존 **fps=10, loop=yes, frame_w=256, render_scale=1.37** 유지. 게임 루프는 **2.4초**, 동봉 GIF는 120ms×24=2.88초다. 미리보기와 게임 속도가 같다고 주장하지 않는다. 속도·몸 크기 보정값은 실제 재생 확인 전 임의 조정하지 않았다.
- 변환된 24개 셀이 원본 공통 변환 결과와 바이트 단위로 일치함을 검사했다. [24칸 정적 대조표](../../assets/references/revenant-dragon/fly24-2026-11-19/contact.png)에서 방향·주요 외곽과 자세 순서를 확인했다. 기존 비행 키 자세가 유지되지만 중간 날개가 늘어나거나 흐려지는 부분은 최종 품질 승인이 아니다.

### 망계의 업화 V5 시각 개선

V5 타이밍 커밋을 기준으로 기존 본체 40칸과 브레스·충돌·독립 화염 시트를 재사용했다.

시전 타이밍(도약 0.4초, 비행·분사 2초, 착지 0.4초), 비행 거리, 피해 영역 및 피해율은 V5 값을 사용한다.

#### 입 시안 A + B

1536×1024 입 시안에서 A의 회전·수렴을 사용하고, B의 레이어 예시의 형상을 사용한다. B의 색 기준은 영혼불 `#00FFD9`, 보조 `#6FFFEF`, 코어 `#BFFFFF`다. B 예시에서 입 벌어진 영역 대비 효과 목표 폭은 1.6–2.4배, 높이는 1.4–2.0배다. 실제 비교에서는 같은 시점의 아래턱과 윗턱을 기준으로 정렬한다.

| 레이어 | 원본과 움직임 |
|---|---|
| L1 후면 | 입 뒤쪽의 끊어진 회전 화염 한 덩어리. 입 앵커 주위를 돌며 시전 후반 반경이 줄어든다. |
| L2 코어 | 입 앵커의 민트색 코어 한 덩어리. 발사 직전 가장 조밀하고 발사 후 밝기가 줄어든다. |
| L3 왕관 | B의 입 앞쪽 갈라지는 긴 곡선형 화염. 발사 순간 기존 분사축으로 회전해 펼쳐진다. 후면 화염보다 밝고 두껍다. |
| L4 파편 | B의 분리된 작은 영혼 불꽃 묶음. 왕관과 같은 축을 따르며 왕관보다 약하게 바깥으로 흩어진다. |

준비는 게임의 기존 0.4초 도약 안에서 0.05초 단위로 대조한다. 0.00초 형상 없음, 0.05초 불씨, 0.10·0.15초 회전 형성, 0.20·0.25초 수렴, 0.30·0.35초 코어 집중, 0.40초 왕관 전개, 0.45초 첫 확장이다. 2.4초 분사 종료 전에 왕관과 파편을 감쇠한다. 합성 순서는 L1 → 골격 → 브레스 위의 L3·L4 → 입 중앙 L2다.

**에셋과 위치.** `tools/make_soulfire_vfx.py <날개 시안 PNG> <입 시안 PNG>`에서 두 원본의 예시 영역을 잘라 12×128×128 RGBA 가로 시트 6종을 생성한다. 알파 64 이상인 첫 셀의 경계 `(x0,y0,x1,y1)`는 후면 날개·꼬리 `(12,42,111,93)`, 전면 바람 `(17,45,110,76)`, L1 `(23,33,105,91)`, L2 `(44,49,81,81)`, L3 `(6,24,102,110)`, L4 `(26,35,105,89)`다. 면적과 색은 원본의 합성 픽셀을 기준으로 추출했다. 평면 원본의 후면 가림과 원본 알파는 복원할 수 없다. 합성은 게임의 알파 블렌딩을 쓴다.

본체 원본 256px 좌표는 `Renderer.cpp`의 `kSoulfireAnchors`, `kSoulfireTailTips`, `earlyMouth`에 포즈별로 기록했다. 예를 들어 원본 셀 20의 날개 끝·찢어진 막·꼬리 끝·입은 각각 `(74,49) / (96,95) / (29,136) / (192,149)`다. 후면 날개 뿌리는 끝점 65%와 막 35%를 섞어 전방으로 24px 옮기고, 꼬리는 끝점에서 전방 36px에서 시작한다. 각각의 잔불은 같은 뿌리에서 뒤로 이동한다. L1은 준비 시 270°만큼 회전하며 시트 폭을 본체 칸 폭의 0.66→0.44배로 줄인다. L3의 시트 폭은 분사 시작 65ms 동안 본체 기준의 0.34→0.65배가 된다. L4는 같은 분사축에서 왕관보다 전방으로 이동한다.

**비교 QA.** Windows 자동 캡처에서 좌우, 50·100·150% 크기, 밝고 어두운 배경을 조합한 수정 전후 156쌍을 비교했다. 기존과 같은 시간·카메라에서 84쌍이 바뀌었고 대기 및 2.69초 이후의 72쌍이 픽셀 단위로 일치했다. 100% 우향 어두운 배경에서 밝기 차이 8 초과 픽셀은 0.32초 1,283개, 0.54초 1,700개, 1.23초 1,754개였다. 첫 렌더에서 왕관이 초과 확장되고 꼬리 리본이 날개와 겹쳐 왕관의 최대 폭을 0.84→0.65배, 꼬리 리본의 세로를 0.74배로 줄인 뒤 재캡처했다. 정지 시안과 게임은 포즈가 달라 같은 몸통 폭에 가깝게 맞춰 비교했으며 원본의 절대 시점과 입 벌림 대비 비율의 일치는 미확정이다. 브레스와 지면 화염은 기존 V5 에셋을 사용한다.

Windows 미리보기는 수정된 렌더러로 다시 빌드해 실행했다. 기존 코어·에셋 검사 8종을 실행해 모두 통과했다. 일반 CMake 빌드는 로컬 MSVC 구성 오류로 별도 미리보기 빌드로 우회했다. Windows 실제 플레이에서 합성·적과의 가림·연속 시전·프레임 시간은 미검증이다.

Windows x64 Release의 게임과 프리뷰 빌드, CTest 8종, 신규 RGBA 5종의 칸 검사 완료. 자동/수동, 제자리 시전, 좌우 발사, 다중 관통과 대상별 한 차례 피해를 코어 테스트로 확인했다. Windows 프리뷰는 각 버전에서 4가지 방향·크기 조합으로 30시점씩 캡처했다. 실전 바탕화면 오버레이의 입력·가림·성능은 확인이 남아 있다.
