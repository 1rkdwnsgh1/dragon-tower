이미지 358장 포함 원본 파일 407개를 그대로 보관했다. 세트별 위치·출처·검수 상태는 [복구 자료 색인](../../assets/references/revenant-dragon/recovered-2026-11-16/README.md)을 따른다.
기존 게임 파일을 교체하거나 스킬을 구현한 작업은 아니다. 아래 11월 13일 기록과 구분한다.

기록일: 2026-11-13. [캐릭터 기획](revenant-dragon.md)의 디자인 기준을 유지한다.

## 자료 보관

사용자가 지정한 바탕화면 `드래곤 타워/gpt 작업용 레퍼런스` 폴더의 파일 14개를 백업 하위 폴더까지 포함해 [작업 자료 폴더](../../assets/references/revenant-dragon/work-2026-11-13/)에 원본 파일명과 구조 그대로 보관했다. PNG·ZIP은 Git LFS로 관리한다. ZIP 내부 원본·프레임·미리보기·보고서를 그대로 보존하며, 패키지의 코드나 HTML은 이번 보관 작업에서 실행하지 않았다.

[manifest.json](../../assets/references/revenant-dragon/work-2026-11-13/manifest.json)에 파일별 크기와 SHA-256을 기록하고 원본과 복사본의 일치를 확인했다. Git으로 받을 때는 Git LFS 설치 후 `git lfs pull`로 실제 자료를 내려받는다.

## 다음 확인 사항

- `REVENANT_SOUL_MIST_WALK_V1`은 생성 결과부터 검수하고 필요한 수정을 진행한다.
- 나머지 패키지도 동봉 QA 보고서의 미해결 항목과 실제 정상·저속 반복 재생을 확인한 뒤 사용 승인 여부를 결정한다.
- 공식 외형과 프레임별 골격·뿔·비대칭 날개 손상·코어 위치를 비교한다. 패키지의 왼쪽 지향 이미지와 현재 게임의 오른쪽 지향·좌우 반전 규격도 검토한다.
- 현재 게임의 정지 이미지 표시와 애니메이션 제작물 보관을 구분한다. 애니메이션 로더, 상태 전환, 망령룡 종류 ID 및 스킬은 이번 작업에서 구현·확정하지 않았다.

개발 로드맵 단계 완료나 게임 적용 승인은 별도 확인 사항이다.
