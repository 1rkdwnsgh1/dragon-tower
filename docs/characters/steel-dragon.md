# 강철룡 A안 — 용광로 핵심형

2026-11-24 확정. 플레이용 종 키는 `steel_dragon`이다. [종 등록 PR #123](https://github.com/1rkdwnsgh1/dragon-tower/pull/123)

## 확정 외형 — Furnace Core Type

오른쪽을 향하는 육중한 4족 기계 드래곤이다. 건메탈·차콜 다층 강철 갑주, 밝은 주황색 흉부 용광로 코어, 날카로운 기계식 왕관형 뿔, 등 방열판, 주황색 발광막의 기계식 날개, 분절 금속 꼬리와 창날을 유지한다. 작은 게임 화면에서 큰 구조와 강한 색상 대비를 우선한다. 장갑 모서리의 밝은 면으로 판과 관절을 구분한다.

승인된 측면 마스터 ‘주황빛 날개를 펼친 강철 드래곤.png’가 외형 기준이다. 게임 시트의 원본과 해시는 [에셋 출처](../../assets/dragons/steel_dragon/CREDITS.md)에 기록했다.

## IDLE과 HEAVY VENT V5

승인된 256×256 IDLE 시트를 사용한다. 구형 날개·꼬리 연기가 들어 있던 시트는 Git 이력에서 확인할 수 있다. IDLE에서는 패키지의 합성 미리보기 순서대로 IDLE F01–F24 → VENT F01–F20 → IDLE F02–F24를 재생한다. 배기 구간에는 별도의 16프레임 VENT 본체를 사용하며 F17–F20에 F16을 유지한다. 288×288 FX는 본체 셀 기준 (-16, -24)에 그린다. 총 67프레임, 약 5.58초에 한 번 반복하며 다른 상태로 나가면 배기가 끝난다. 사용자가 Windows 적용을 확인했다.

여러 상태에서 사용할 독립 입자의 배출구 추적과 상태별 강도·빈도 설계는 후속 과제다.

## FLY 비행

승인된 왼쪽 지향 6×4 원본을 행 우선으로 나누고 좌우 반전한다. 모든 몸체와 FX에 같은 62.5% 균일 축소와 기준점을 적용한다. 256×256 본체 셀에서 반전한 250px 폭을 x=5, 원본 상단을 y=6에 놓는다. 본체·FX는 같은 렌더링 중심을 사용하므로 384×384 FX 셀은 본체보다 각 변이 64px씩 넓다. FX 제작 셀에서 본체는 (12, 0)에 있었으며 변환에도 이를 반영한다.

렌더러는 본체의 프레임 인덱스로 연기와 화염을 선택하고 본체 → 연기 → 화염 순서로 그린다. 각 소스 레이어의 가림은 승인 알파에 포함되어 있다. 이동·반전·확대에 본체와 같은 변환을 쓰며, FLY를 벗어나면 두 FX를 그리지 않는다. PNG는 기존 시트 로더에서 읽고 렌더링은 기존 프레임 캐시를 사용한다.

추진 화염 V2는 뿔 안쪽, 어깨·앞다리·날개 연결부, 다리·몸통 하부와 날개 후면에서 지속된다. VENT V2는 목 뒤, 어깨·날개 기저부, 몸통 중앙과 꼬리 기저부의 검은 후방 배기다. 사용자가 24프레임·12 FPS·2초 버전의 Windows 적용을 확인했다. 후속 확장에서는 승인 키프레임을 보존하고 추가 프레임에 두 FX를 다시 정렬한다.

## WALK 보행 V2

승인된 8개 키프레임 V2를 F01·F03·…·F15에 그대로 넣은 16프레임 버전이다. 네 다리의 독립적인 상승·전진·접지·후퇴와 어깨·흉부·골반의 하중 이동을 유지한다. 짝수 중간 자세는 승인본에 포함된 상·하박 연결과 관절 가림을 그대로 사용한다.

1800×904px 우향 셀의 공통 기준점 (900, 842)을 (128, 240)으로 옮기고, 개별 포즈 정렬 없이 249/1713의 균일 배율을 적용했다. 4096×256px RGBA 한 줄 시트를 기존 `MOVE`에 연결했다. 캐릭터 윤곽 폭은 IDLE 249px, WALK 248–250px이다. IDLE의 기존 알파 하단은 WALK보다 4 셀 픽셀 낮다.

게임 코어의 기본 바탕화면 보행은 1초에 59.50 게임 px였다. 승인 시트의 연속 접지 발은 프레임당 제작 좌표에서 약 7px 후퇴한다. 100% 표시 크기에서 환산하면 1초당 약 6.49 게임 px다. 따라서 접지 발이 표시 기준으로도 전진하는 미끄러짐이 남는다. 승인된 16 FPS와 기존 이동 규칙을 유지했다.

### 보행 제작 이력

- WALK V1에서는 어깨가 거의 고정돼 다리 하부가 잘라 붙인 것처럼 움직이고 상체와의 연결감이 약했다.
- KEYFRAMES V2에서 어깨·흉부의 하중 반응, 어깨/고관절부터 이어지는 기계식 관절, 날개·꼬리의 작은 관성 반응을 강화했다.
- WALK 16F V2는 승인 8개 자세의 픽셀을 보존하고 중간 자세 8개를 추가했다. 사용자 확인 후 MOVE 본체에 적용했다.

## WALK VENT V2.1

V1은 검은 산업용 연기의 생성·성장·이동·소멸을 구현했으며 작은 게임 크기에서는 존재감이 약했다. V2는 어깨·등 연기의 규모를 키우고 소형 용광로 불씨를 추가했다. 승인된 V2.1은 기존 네 시트를 이어받고 날개 하부 안쪽과 몸통 측면 상부의 이음매에 보조 연기와 불씨를 추가했다.

기존 어깨·날개 기저부, 등 방열부, 몸통 중후부 및 꼬리 기저부 방향의 흐름은 원본 레이어에 유지된다. 새 배출구의 마스터 기준은 (867, 504)이며 포즈별 배출점은 원본 `alignment.json`에 있다. 어깨보다 작은 연기가 위와 뒤로 퍼지고, 작은 황색·주황색·적주황색 불씨가 식으며 사라진다. 날개막 위는 승인 알파가 가림을 줄인다.

원본의 연기 네 장과 불씨 두 장을 각 그룹 내에서 지정 순서로 합성했다. 본체와 같은 균일 배율과 기준점을 사용한 256px 셀 두 시트를 만들고 **본체 → 연기 → 불씨** 순서로 그린다. 16프레임의 본체 인덱스·중심·배율·반전을 공유한다. 여러 입자의 움직임과 포즈별 배출점은 프레임에 기록돼 있고, 게임에서는 전체 프레임이 캐릭터를 따라간다. 기존 시트 로더와 프레임 캐시를 사용하며 MOVE가 끝나면 WALK 연기와 불씨가 그려지지 않는다.

## Windows 검수

Windows x64 Release 빌드와 CTest 8종(종 선택·저장 복원·에셋 검사 포함), 공식 시트 46개와 문서 검사를 통과했다. Windows 렌더러 미리보기에서 FLY 24개 슬롯, 2초 루프 경계, 좌우 반전, 100%·150% 확대, IDLE 배기와 다른 상태의 FX 종료를 확인했다.

사용자가 Windows에서 IDLE·FLY·WALK 본체를 확인했다. V2.1 통합의 Windows x64 Release, CTest 8종(에셋·종 선택·저장 복원·상태 전환 포함), 공식 시트 46개와 문서 검사가 통과했다. Windows 렌더러에서 MOVE 16프레임·1초 루프·좌우·100% 및 150% 배율, IDLE과 FLY의 기존 FX, ATTACK에서 FX 미출력, 망령룡 이동 표시를 확인했다.

## 기본공격 — 용광로 화염탄

- **BASIC ATTACK 10F V1**은 16 FPS·0.625초 1회 재생이다. 흉부, 목, 어깨, 몸통 슬릿과 입의 독립 HEAT LEAK 레이어가 본체와 같은 프레임·변환을 쓴다. F01·F10은 추가 발광이 없고 F06에서 발광과 턱 개방이 최대다.
- **PROJECTILE FX V2**는 둥근 황백색 탄두와 길게 흐르는 화염으로, 8F·16 FPS·0.5초 반복이다. F06 시작(312.5ms)을 통과할 때 현 위치의 입에서 한 번 발사한다. 제작 셀 (1210, 370)은 게임 256px 셀의 약 (247.79, 190.61)이다. 발사 순간 표적 쪽 직선을 정하고 좌우·각도를 맞춰 탄두를 투사체 좌표에 그린다.
- **HIT FX V2 D안**은 불규칙한 화염 파열과 잔열 파편으로, 8F·16 FPS·0.5초를 충돌점에서 한 번 재생한다. F08은 투명 종료 프레임이다. 지정 표적과 처음 교차할 때 피해를 한 번 적용하고 투사체는 제거한다. 사거리 또는 화면 밖에서도 제거된다. 최대 이동 시간은 약 0.442초여서 0.5초 비행 FX는 한 발에서 한 주기 전에 끝날 수 있다.

기존 자동 기본공격과 쿨다운 0.9초, 표적 선택거리 230 게임 px, 투사체 520 게임 px/초, 공격력 1.0배를 사용한다. 강철룡의 투사체는 발사 후 직선으로 진행하므로 움직이는 표적이 피할 수 있다. ATTACK은 표시 상태이며 이동은 계속 처리된다. 발사 전 조준은 표적 쪽을 향하고, 발사 이후 이동 방향을 따라 반전한다. 대기·걷기 배기는 각자 해당 상태에서 재생하며 ATTACK에서는 HEAT LEAK를 표시한다. 기존 전투 규칙은 전투 중 자동 비행을 비활성화한다.

기본공격 통합의 Windows x64 Release, CTest 8종, 에셋·시트·문서 검사가 통과했다. 코어에서 F06 경계·건너뛰는 틱, 이동 중 발사, 좌향·150% 입 좌표, 피해 1회, 명중 FX 만료, 직선 빗나감·사거리 제거와 쿨다운 후 재공격을 검증했다. Windows 애니메이션 미리보기의 강철룡 **공격**은 실제 전투 경로를 고정 표적에 실행한다. 발사 직전·직후와 0.5초 명중 FX 만료, 좌우 및 확대를 캡처했다. 사용자가 Windows 실전에서 기본공격 정상 작동을 확인하고 병합을 승인했다.

이전의 U/C자 불똥 시각 방향은 제작 초기 시안이었다. 현재 플레이 검수에서는 전투 중 이동, 가까운 표적에 대한 발사 가독성과 312.5ms 준비 시간의 체감, 좌우·배율별 표시를 확인한다.

## 스킬 1 — 용광 폭렬탄

Lv.1 투사체 스킬이다. 범위 안의 가장 가까운 적 한 마리를 지정하고 기존 ATTACK·HEAT LEAK를 재생한다. F06(312.5ms)에 현재 입 좌표에서 압축 포탄을 발사한다. 조준과 이동을 분리해 준비 중에도 이동할 수 있다. 발사한 포탄은 기존 스킬 투사체처럼 지정한 적을 추적하며, 표적이 사라지거나 이동 한도를 넘으면 소멸한다.

명중은 대상 몸통 중심에서 발생한다. 직접 대상에는 직접 피해만 한 번, 반경 내 다른 적에는 주변 피해를 한 번 적용한다. 두 시각 링은 추가 피해를 발생시키지 않는다. 지면형 V1은 공중 대상에 부자연스러워 폐기했고, V2에서 타겟 중심형으로 전환했다. 승인 V3는 지연된 2차 링이 1차 링을 따라잡고 F09에서 중심 폭발과 중첩 섬광이 강해진다. 바닥 균열이나 바닥 불꽃 없이 공중·지상 표적에서 같은 좌표계를 쓴다.

폭발은 256px RGBA 12F·20 FPS·0.6초의 1회 시트다. F01·03·05·07·09·11은 승인 V3와 RGBA 픽셀 단위로 같고, 중간 컷은 링 반경·불꽃 조각의 궤적을 제작해 채웠다. F12는 투명이다. 포탄은 새 CORE·ENERGY SHELL·EMBER를 합성한 160×96 RGBA 8F·16 FPS 반복 시트다. 폭발의 표시 셀은 100% 크기에서 200px이며, 판정 반경과 독립이다. 재현 스크립트는 [에셋 제작·검사 도구](../../tools/build_steel_furnace_assets.py)다.

`dragon.txt`의 플레이 검수값은 사거리 370px, 4초 재사용, 직접 공격력 1.9배, 주변 직접 피해의 65%, 반경 105px이다. 이동 속도는 기존 스킬 투사체 기본값 572px/s를 재사용하고, 발사 후 이동 한도는 스킬 사거리다. 최종 밸런스와 생성 중간 컷·포탄 시각 승인은 사용자 검수 대상이다. Windows Release, CTest 8/8, 에셋·시트·문서 검사와 Windows 프리뷰의 지상 100% 및 공중 150% 캡처를 확인했다. 실전 플레이는 미검증이다.

## 스킬 2 — 노심 과열파 (용광 해방형)

승인 콘셉트의 선명한 원형 열충격파와 풍성한 중심 화염을 결합한다. 0.22초 동안 흉부·목·갑주 틈을 가열한 뒤 시전자 본체의 현재 월드 좌표에서 한 번 폭발한다. 중심 불꽃은 본체를 잠시 가릴 수 있다. 원형 충격파는 본체 뒤, 중심 섬광·불꽃·불씨는 앞에 재생되며 바닥이나 두 번째 추격 링에 의존하지 않는다.

현재 폭발은 Work 승인 **V2**다. 384×384 RGBA 셀 16개를 한 줄에 배치하며, 기준점 (192, 192)에서 20 FPS·0.8초로 한 번 재생한다. 승인 시트에서 본체 뒤에는 방사형 화염 → 검은 연기 → 원형 파동, 본체 앞에는 중심 폭발 → 불씨가 놓인다. 100% 표시 셀은 기존 264 게임 px다. 승인 PNG 앞뒤 시트가 게임 파일과 바이트 단위로 일치하며 F16은 완전히 투명하다.

V1은 절차적으로 제작한 첫 게임 적용본이다. V2는 화염 부피와 독립 검은 연기를 강화했다. 승인 합성 F08의 알파 128 이상 픽셀은 V1 7,738 → V2 46,120개였고, 먹색 영역은 0 → 14,980개였다(알파 96 이상, RGB 최대 채널 85 미만). 준비와 잔열은 IDLE·WALK·FLY·ATTACK·IDLE VENT의 각 원본 프레임에서 밝기·발광 틈과 주변 금속 영역을 추출해 만든 별도 시트다. 잔열은 0.6초에 걸쳐 감소하고 현재 포즈·위치·반전을 따른다. 첨부된 마스크 5개와 본체 4개는 기존 게임 원본과 바이트 단위로 일치했다. V1 제작 도구는 이력으로 보존한다. [에셋 출처와 해시](../../assets/dragons/steel_dragon/CREDITS.md)

Lv.3의 스킬 2 기본값을 검수값으로 유지했다. 공격력 1.6배, 반경 110 게임 px, 재사용 8초다. 폭발 순간 기존 원형 판정으로 지상과 공중의 적에게 각 한 번 피해를 주며 FX 확장은 피해를 추가하지 않는다. 시전과 냉각은 별도의 시계로 처리하며 이동을 제한하거나 공격 포즈를 강제하지 않는다. 기존 전투 모드의 자동 비행 규칙을 따른다. V2의 Windows Release·CTest 8/8·시트·문서 검사와 IDLE/WALK/FLY 렌더러 비교를 통과했다. 실제 전투 조작은 별도 사용자 검수 대상이다.

## 스킬 3 — 방열 칼날환 V6.1

Work 승인 V6.1의 4개 칼날, 독립 화염·잔상·불씨와 전후 레이어를 사용한다. 원본 아틀라스는 `assets/dragons/steel_dragon/heat_blade/`에 있으며 PNG 원본 바이트를 유지한다. [설치 및 검사 도구](../../tools/install_steel_heat_blade.py)

몸통 기준점에 부착해 실제 경과시간을 60 FPS 시트 인덱스로 바꾼다. START 0.0–0.2초(12F), LOOP 0.2–3.4초(칼날 32F × 6회), END 3.4–4.0초(36F)다. 메인 화염은 32F, 보조는 24F, 속도 잔상과 연기는 192F 시계를 사용한다. 칼날 위치와 원근은 이미 시트에 들어 있다. 본체 애니메이션과 이동 입력을 유지한다.

0.25초 간격으로 4초 동안 몸통 중심 원형 피해를 판정한다. 0.6·1.8·3.0초에 B4를 각 3발 사출한다. 각 묶음은 사거리 내 가까운 서로 다른 적을 우선하며, 기본값은 남는 탄을 전방 부채꼴로 발사한다. `heat_blade_repeat_targets`로 부족한 표적을 재선택할 수 있다. 탄은 발사 방향으로 직진하며 경로의 적을 탄당 한 번씩 관통한다. 발사·피격·소멸 FX는 각각 독립 8F·20 FPS다.

임시값은 Lv.6, 쿨다운 10초, 광역 반경 105 게임 px, 틱당 공격력 0.16배, 탄당 0.44배, 포탄 사거리 420px·속도 780px/s다. 발사체 수명은 회전 FX와 별개다. ZIP의 IDLE/WALK/FLY/LEFT 보고에는 각 WARN 232건이 있으며 주로 프레임 이동과 루프 경계다. 이전 V1~V6은 제작 이력으로 남고 현재 런타임은 V6.1을 사용한다.

## FX 품질과 제작 절차

제작 프롬프트에는 Directional Flow, Temporal Coherence, Spawn–Travel–Dissipate, Shape Persistence, Particle Advection, Burst, Follow-through, Motion Trajectory를 활용한다. 부착 열기의 Flickering과 공간에서의 Flowing을 구분한다. 이동형 FX는 중심점과 위치가 실제로 이동해야 한다.

승인된 RGBA 키프레임을 보존하고 관절과 구조를 고려해 중간 자세를 제작한다. 게임용 변환은 균일 축소, 좌표 정렬과 프레임 배열만 적용한다. 독립 FX에서는 작은 요소를 서로 다른 시점에 발생시켜 성장·이동·소멸과 루프 연결을 만들고, 포즈마다 배출구와 본체 실루엣을 확인한다.

공통 순서는 기획 → 키프레임 → 검수 → 본체 애니메이션 → 게임 적용 → 독립 FX → 합성 검수 → 게임 통합이다. 본체와 FX의 적용 순서를 조정할 수 있으며 원본 보존과 단계별 사용자 승인은 유지한다. 프로젝트의 T7 → T8 순서는 유지한다.

## 후속 제작 순서

1. Windows 실전에서 WALK VENT 가독성·접지·상태 전환과 다른 종의 애니메이션을 확인한다.
2. 승인 FLY 키프레임을 기반으로 추가 자세를 제작하고 추진 화염·VENT의 정렬을 검수한다.
3. 용광로 화염탄의 실제 전투 조작성과 용광 폭렬탄의 중간 컷·포탄·판정 반경 및 밸런스를 검수한다.
4. HIT·DEATH·REST 전용 모션과 강철룡 전용 스킬을 제작한다.

## Legacy — 2026-11-24 폐기

A안 측면 마스터와 독립 배기 방향을 새 제작 기준으로 승인해 아래 외형·연출 계획을 대체했다. 기존 대기를 다른 동작의 최종 기준으로 삼는 계획도 폐기했다. 종 등록과 임시 플레이는 유효하며 기존 게임 코드와 에셋을 보존한다.

- 짙은 금속 장갑판, 뒤로 휜 뿔, 넓은 막날개와 긴 장갑 꼬리를 유지한다. 목과 가슴의 붉은 균열로 내부 열기를 드러낸다.
- 대기 중 몸통 중앙의 날개 뿌리 부근에서 검은 연기가 생긴다. 모양이 다른 연기 덩어리들이 차례로 겹쳐 부풀고, 뒤쪽 위로 올라가 날개 높이에서 흩어진다. 꼬리 아래에서는 옅은 연기가 낮게 새어 나온다.
- 승인된 V4가 날개 연기의 시각 기준이다. 당시 임시 대기 루프는 6초였으며, 본체는 주기마다 한 번 호흡한다. 가슴이 부푼 뒤 1.75초에 가라앉기 시작할 때 날개 연기가 나와 3초간 이어진다. 꼬리 연기는 대기 내내 이어진다. 6초는 플레이에서 빈도를 확인하기 위한 임시값이다.

Windows x64 Release에서 CTest 8/8 통과. 전투 테스트는 4초 주기 피해와 이동, 9발 사출, 직선 관통의 적별 중복 방지 및 종료 정리를 검사한다. Windows 렌더러에서 IDLE·WALK·FLY와 좌향을 고정 시간으로 캡처했다. Work와 Windows 캡처는 카메라와 적 배치가 다르다. 프레임 시간과 메모리 실측은 후속 확인 항목이다. [Windows 캡처](steel-heat-blade-windows.gif) · [Work 비교](steel-heat-blade-work-windows.png)
