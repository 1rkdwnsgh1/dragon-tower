# 강철룡 (Steel Dragon) 캐릭터 기획

강철룡은 겹겹이 쌓인 짙은 강철 장갑과 붉게 달아오른 균열을 가진 드래곤이다. 플레이용 종 키는 `steel_dragon`이다. [종 등록 PR #123](https://github.com/1rkdwnsgh1/dragon-tower/pull/123)

## 외형과 대기 연출

- 짙은 금속 장갑판, 뒤로 휜 뿔, 넓은 막날개와 긴 장갑 꼬리를 유지한다. 목과 가슴의 붉은 균열로 내부 열기를 드러낸다.
- 대기 중 몸통 중앙의 날개 뿌리 부근에서 검은 연기가 생긴다. 모양이 다른 연기 덩어리들이 차례로 겹쳐 부풀고, 뒤쪽 위로 올라가 날개 높이에서 흩어진다. 꼬리 아래에서는 옅은 연기가 낮게 새어 나온다.
- 승인된 V4가 날개 연기의 시각 기준이다. 현재 대기 루프는 6초이며, 본체는 주기마다 한 번 호흡한다. 가슴이 부푼 뒤 1.75초에 가라앉기 시작할 때 날개 연기가 나와 3초간 이어진다. 꼬리 연기는 대기 내내 이어진다. 6초는 플레이에서 빈도를 확인하기 위한 임시값이다.

## 전투 기획과 남은 검수

- 전투 역할, 전용 능력치·성장, 전용 스킬은 미정이다. 종 등록에는 신규 종 기본값을 사용한다.
- 전용 이동·비행·전투 모션을 만들 때는 승인된 장갑, 날개, 꼬리 실루엣을 기준으로 삼는다.
- Windows Release 빌드와 CTest 8종, 시트 검사가 종 등록 시 통과했다. 코어 테스트에서 종 선택·저장 복원을, Windows 미리보기에서 연기와 좌우 반전·대체 이동·비행을 확인했다.
- 실제 게임에서는 종 선택 카드와 입력, 선택 후 대기 연출, 저장 후 재실행 복원을 확인한다. 일반 플레이 화면에서 날개 연기의 반복 빈도를 검수한 뒤 주기를 확정한다.
