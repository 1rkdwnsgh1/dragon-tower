# 강철룡 A안 — 용광로 핵심형

2026-11-24 확정. 플레이용 종 키는 `steel_dragon`이다. [종 등록 PR #123](https://github.com/1rkdwnsgh1/dragon-tower/pull/123)

## 확정 외형

오른쪽을 향하는 육중한 4족 기계 드래곤이다. 차콜 블랙 강철 갑주, 밝은 주황색 흉부 용광로 코어, 날카로운 기계식 왕관형 뿔, 등 방열판, 주황색 발광막의 기계식 날개, 분절 금속 꼬리와 창날을 유지한다. 작은 게임 화면에서 큰 구조와 강한 색상 대비를 우선한다. 장갑 모서리의 밝은 면으로 판과 관절을 구분한다.

최종 승인된 신규 측면 마스터가 외형 기준이다. 저장소에 해당 이미지를 확인할 수 없어 원본 업로드를 후속 작업으로 남긴다.

## 제작 현황

| 동작 | 상태 |
|---|---|
| IDLE | V3 승인. 용광로 호흡 및 기계 관절 운동 |
| VENT | V5 제작. 검은 배기 및 잔류 연기 |
| WALK | 제작 진행 중 |
| FLY | 연출 방향 확정. 본체 및 FX 제작 예정 |
| REST | 미기획 |
| ATTACK | 기본공격 방향 확정. 에셋 제작 예정 |
| HIT | 미기획 |
| DEATH | 미기획 |

신규 IDLE은 용광로 밝기와 기계 관절 운동으로 호흡을 표현한다. VENT에서는 등 방열판 아래 배기구가 열리고, 검은 배기가 뒤쪽 위로 흐르며 잔류한다. 접지와 실루엣을 유지하고 용광로가 가려지지 않도록 게임 표시 크기에서 검수한다.

[현재 게임 에셋](../../assets/dragons/steel_dragon/CREDITS.md)은 96프레임 IDLE과 연기 없는 이동·비행·휴식·공격·피격·사망 대체 시트다. 종 등록과 임시 플레이에 사용한다. 신규 V3/V5 파일의 업로드 및 통합 검수가 끝나면 교체한다. 전투 역할, 전용 능력치·성장·스킬은 미정이다.

## 공통 배기 FX 시스템 V1

구현 대기. 한 배기 FX를 IDLE·WALK·FLY·REST·ATTACK·HIT·DEATH에서 재사용한다. V5 레이어는 `PRIMARY_STEAM`, `DARK_SMOKE`, `PRESSURE_WAVE`, `HEAT_GLOW`다.

- 본체와 FX는 독립 재생한다. 각 본체 프레임의 배출구 앵커를 추적해 현재 위치에서 새 연기를 생성한다.
- 이미 분리된 배기는 자체 공간 위치와 시간축을 유지한다.
- 동작별 강도·빈도·배출 방향과 동시 출력량 상한을 설정한다. 데이터와 재생 구조는 다른 드래곤도 재사용할 수 있도록 설계한다.

| V5 기준 | 값 |
|---|---|
| IDLE / VENT 본체 | 24 / 16프레임 |
| FX | 20프레임, 12 FPS |
| 본체 / FX 칸 | 256×256 / 288×288px |
| 발 기준점 | (128, 240) |
| VENT 배출구 앵커 | (141.4, 185.29) |
| 기존 합성 오프셋 | (-16, -24) |

다른 모션의 배출구 앵커는 측정 대기다.

## FLY 비행 모션 V1

느린 중량형 날갯짓, 용광로 추진력과 날개 화염을 사용한다. 망령룡보다 날갯짓 횟수를 줄이고 관절과 피스톤을 활용한다. 날개막과 골격에 주황빛 열기가 흐르며, 강하게 내려칠 때 용광로 추진력과 폭발형 화염이 나타난다. 화염은 뒤로 길게 이어져 불티를 남기며 V5 검은 배기를 재사용한다. 비행 중 다리는 접고 꼬리는 뒤로 뻗는다.

임시 제작 사양은 **36프레임, 12 FPS, 3초 루프**다. 프레임 수와 세부 타이밍은 승인 대기다.

| 프레임 | 연출 |
|---|---|
| F01–09 | 날개 상승, 피스톤 압축 |
| F10–17 | 강한 날개 하강, 폭발형 화염 |
| F18–27 | 활공, 화염 궤적, 잔류 연기 |
| F28–36 | 날개 복귀, 추진력 보조 |

## 날개 화염 FX

선명한 2D 셀과 손그림 폭발 FX를 쓴다. 노랑·주황·적주황의 대비, 큰 실루엣과 명확한 움직임을 우선한다. 고열 에너지 흐름, 폭발형 화염, 유선형 궤적, 용융 금속 불티로 구성한다. 부착 열기는 날개에 붙어서 일렁이며, 분리된 불꽃과 입자는 실제 공간에서 이동한다.

## 기본공격 — 용광로 불똥 V1

확정된 연출 방향은 오른쪽을 향하는 작은 U/C자형 불똥이다. 밝은 노란 중심과 주황 외곽, 짧은 화염 꼬리와 소량의 불티를 쓰고 빠르게 직진한다. 드래곤이 턱을 짧게 열어 입에서 발사한다. 명중 시 작고 선명한 화염 파열을 표현한다. 투사체와 명중 FX는 제작 대기다.

제작 순서는 투사체 정지 시안 → 이동 애니메이션 → 명중 FX → 본체 발사 모션 연동이다.

## FX 품질과 제작 절차

제작 프롬프트에는 Directional Flow, Temporal Coherence, Spawn–Travel–Dissipate, Shape Persistence, Particle Advection, Burst, Follow-through, Motion Trajectory를 활용한다. 부착 열기의 Flickering과 공간에서의 Flowing을 구분한다. 이동형 FX는 중심점과 위치가 실제로 이동해야 한다.

공통 순서는 마스터 이미지 → 핵심 키프레임 → 본체 애니메이션 → 독립 FX → 통합 검수 → 게임 적용이다. FLY는 핵심 키프레임 6장 → 본체 36프레임(임시) → 날개 화염 → V5 공통 배기 연동 → 게임 크기 검수 → 최종 적용 순서로 진행한다. 승인 원본을 다음 단계에 재사용한다. 프로젝트의 T7 → T8 순서는 유지한다.

## Legacy — 2026-11-24 폐기

A안 측면 마스터와 독립 배기 방향을 새 제작 기준으로 승인해 아래 외형·연출 계획을 대체했다. 기존 대기를 다른 동작의 최종 기준으로 삼는 계획도 폐기했다. 종 등록과 임시 플레이는 유효하며 기존 게임 코드와 에셋을 보존한다.

- 짙은 금속 장갑판, 뒤로 휜 뿔, 넓은 막날개와 긴 장갑 꼬리를 유지한다. 목과 가슴의 붉은 균열로 내부 열기를 드러낸다.
- 대기 중 몸통 중앙의 날개 뿌리 부근에서 검은 연기가 생긴다. 모양이 다른 연기 덩어리들이 차례로 겹쳐 부풀고, 뒤쪽 위로 올라가 날개 높이에서 흩어진다. 꼬리 아래에서는 옅은 연기가 낮게 새어 나온다.
- 승인된 V4가 날개 연기의 시각 기준이다. 현재 대기 루프는 6초이며, 본체는 주기마다 한 번 호흡한다. 가슴이 부푼 뒤 1.75초에 가라앉기 시작할 때 날개 연기가 나와 3초간 이어진다. 꼬리 연기는 대기 내내 이어진다. 6초는 플레이에서 빈도를 확인하기 위한 임시값이다.
