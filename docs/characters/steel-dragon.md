# 강철룡 A안 — 용광로 핵심형

2026-11-24 확정. 플레이용 종 키는 `steel_dragon`이다. [종 등록 PR #123](https://github.com/1rkdwnsgh1/dragon-tower/pull/123)

## 확정 외형

오른쪽을 향하는 육중한 4족 기계 드래곤이다. 차콜 블랙 강철 갑주, 밝은 주황색 흉부 용광로 코어, 날카로운 기계식 왕관형 뿔, 등 방열판, 주황색 발광막의 기계식 날개, 분절 금속 꼬리와 창날을 유지한다. 작은 게임 화면에서 큰 구조와 강한 색상 대비를 우선한다. 장갑 모서리의 밝은 면으로 판과 관절을 구분한다.

승인된 측면 마스터 ‘주황빛 날개를 펼친 강철 드래곤.png’가 외형 기준이다. 게임 시트의 원본과 해시는 [에셋 출처](../../assets/dragons/steel_dragon/CREDITS.md)에 기록했다.

## IDLE과 HEAVY VENT V5

승인된 256×256 IDLE 시트를 사용한다. 구형 날개·꼬리 연기가 들어 있던 시트는 Git 이력에서 확인할 수 있다. IDLE에서는 패키지의 합성 미리보기 순서대로 IDLE F01–F24 → VENT F01–F20 → IDLE F02–F24를 재생한다. 배기 구간에는 별도의 16프레임 VENT 본체를 사용하며 F17–F20에 F16을 유지한다. 288×288 FX는 본체 셀 기준 (-16, -24)에 그린다. 다른 상태로 나가면 배기가 끝난다.

여러 상태에서 사용할 독립 입자의 배출구 추적과 상태별 강도·빈도 설계는 후속 과제다.

## FLY 비행

승인된 왼쪽 지향 6×4 원본을 행 우선으로 나누고 좌우 반전한다. 모든 몸체와 FX에 같은 62.5% 균일 축소와 기준점을 적용한다. 256×256 본체 셀에서 반전한 250px 폭을 x=5, 원본 상단을 y=6에 놓는다. 본체·FX는 같은 렌더링 중심을 사용하므로 384×384 FX 셀은 본체보다 각 변이 64px씩 넓다. FX 제작 셀에서 본체는 (12, 0)에 있었으며 변환에도 이를 반영한다.

렌더러는 본체의 프레임 인덱스로 연기와 화염을 선택하고 본체 → 연기 → 화염 순서로 그린다. 각 소스 레이어의 가림은 승인 알파에 포함되어 있다. 이동·반전·확대에 본체와 같은 변환을 쓰며, FLY를 벗어나면 두 FX를 그리지 않는다. PNG는 기존 시트 로더에서 읽고 렌더링은 기존 프레임 캐시를 사용한다.

## WALK 보행 V2

승인된 8개 키프레임 V2를 F01·F03·…·F15에 그대로 넣은 16프레임 버전이다. 네 다리의 독립적인 상승·전진·접지·후퇴와 어깨·흉부·골반의 하중 이동을 유지한다. 짝수 중간 자세는 승인본에 포함된 상·하박 연결과 관절 가림을 그대로 사용한다.

1800×904px 우향 셀의 공통 기준점 (900, 842)을 (128, 240)으로 옮기고, 개별 포즈 정렬 없이 249/1713의 균일 배율을 적용했다. 4096×256px RGBA 한 줄 시트를 기존 `MOVE`에 연결했다. 캐릭터 윤곽 폭은 IDLE 249px, WALK 248–250px이다. IDLE의 기존 알파 하단은 WALK보다 4 셀 픽셀 낮다. WALK 전용 FX는 후속 작업이다. FLY 본체 프레임 확장도 별도 제작에서 검토하며, 추가 프레임에 맞춰 두 FX의 정렬과 동기화를 다시 검수한다.

게임 코어의 기본 바탕화면 보행은 1초에 59.50 게임 px였다. 승인 시트의 연속 접지 발은 프레임당 제작 좌표에서 약 7px 후퇴한다. 100% 표시 크기에서 환산하면 1초당 약 6.49 게임 px다. 따라서 접지 발이 표시 기준으로도 전진하는 미끄러짐이 남는다. 승인된 16 FPS와 기존 이동 규칙을 유지했다.

## Windows 검수

Windows x64 Release 빌드와 CTest 8종(종 선택·저장 복원·에셋 검사 포함), 공식 시트 46개와 문서 검사를 통과했다. Windows 렌더러 미리보기에서 FLY 24개 슬롯, 2초 루프 경계, 좌우 반전, 100%·150% 확대, IDLE 배기와 다른 상태의 FX 종료를 확인했다.

사용자가 Windows에서 IDLE·FLY 정상 작동을 확인했다. WALK 통합 후 Windows x64 Release, CTest 8종, 시트 46개와 문서 검사가 통과했다. 코어에서 IDLE ↔ WALK, WALK ↔ FLY, 좌우 이동을 확인했다. Windows 렌더러에서는 WALK 전 프레임, 1초 루프 경계, 좌우, 100%·150% 배율과 IDLE·FLY FX를 확인했다. 실제 플레이 중 접지와 전환은 후속 검수 항목이다.

## 기본공격 — 용광로 불똥 V1

확정된 연출 방향은 오른쪽을 향하는 작은 U/C자형 불똥이다. 밝은 노란 중심과 주황 외곽, 짧은 화염 꼬리와 소량의 불티를 쓰고 빠르게 직진한다. 드래곤이 턱을 짧게 열어 입에서 발사한다. 명중 시 작고 선명한 화염 파열을 표현한다. 투사체와 명중 FX는 제작 대기다.

제작 순서는 투사체 정지 시안 → 이동 애니메이션 → 명중 FX → 본체 발사 모션 연동이다.

## FX 품질과 제작 절차

제작 프롬프트에는 Directional Flow, Temporal Coherence, Spawn–Travel–Dissipate, Shape Persistence, Particle Advection, Burst, Follow-through, Motion Trajectory를 활용한다. 부착 열기의 Flickering과 공간에서의 Flowing을 구분한다. 이동형 FX는 중심점과 위치가 실제로 이동해야 한다.

공통 순서는 마스터 이미지 → 핵심 키프레임 → 본체 애니메이션 → 독립 FX → 통합 검수 → 게임 적용이다. 승인 원본을 다음 단계에 재사용한다. 프로젝트의 T7 → T8 순서는 유지한다.

## Legacy — 2026-11-24 폐기

A안 측면 마스터와 독립 배기 방향을 새 제작 기준으로 승인해 아래 외형·연출 계획을 대체했다. 기존 대기를 다른 동작의 최종 기준으로 삼는 계획도 폐기했다. 종 등록과 임시 플레이는 유효하며 기존 게임 코드와 에셋을 보존한다.

- 짙은 금속 장갑판, 뒤로 휜 뿔, 넓은 막날개와 긴 장갑 꼬리를 유지한다. 목과 가슴의 붉은 균열로 내부 열기를 드러낸다.
- 대기 중 몸통 중앙의 날개 뿌리 부근에서 검은 연기가 생긴다. 모양이 다른 연기 덩어리들이 차례로 겹쳐 부풀고, 뒤쪽 위로 올라가 날개 높이에서 흩어진다. 꼬리 아래에서는 옅은 연기가 낮게 새어 나온다.
- 승인된 V4가 날개 연기의 시각 기준이다. 현재 대기 루프는 6초이며, 본체는 주기마다 한 번 호흡한다. 가슴이 부푼 뒤 1.75초에 가라앉기 시작할 때 날개 연기가 나와 3초간 이어진다. 꼬리 연기는 대기 내내 이어진다. 6초는 플레이에서 빈도를 확인하기 위한 임시값이다.
