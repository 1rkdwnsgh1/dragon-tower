# 알려진 문제와 고칠 것

게임을 돌려 보고 나온 문제를 모은다. 고치면 이 목록에서 빼고 [변경 기록](changelog.md)에 옮긴다.
**원인을 모르는 채로 수치만 바꾸는 임시 처방은 적지 않는다** — 왜 그런지와 함께 적는다.

항목마다 적을 것: **무엇이 어떻게 보이는가 / 어디를 봐야 하는가 / 왜 아직 안 고쳤는가.**

---

## 1. ~~작업표시줄 꾸미기가 아이콘과 시계를 가린다~~ — 고쳤다 (2026-11-17)

[이슈 #77](https://github.com/1rkdwnsgh1/dragon-tower/issues/77). 띠를 작업표시줄 **위에
덮던 것을 바로 바깥쪽에 그리도록** 바꿨다(작업표시줄이 위쪽에 붙어 있으면 아래쪽).

**덮어 그리면서 아이콘만 피하는 길은 없었다.** 작업표시줄은 explorer 의 창이고 Windows 11 은
그 안이 WinUI XAML 이라 그 밑으로 파고들 수 없다 — `SetParent` 는 성공해 z-index 0 을 얻고
`WM_PAINT` 까지 받지만 **한 픽셀도 그려지지 않는다**(25H2 실측). 구형 Deskband 는 Windows 7
이후 호스트가 없다. explorer 에 DLL 을 주입하는 방식(Windhawk·Classic Shell)은 백신 오탐·
explorer 크래시·업데이트마다 깨짐 때문에 **쓰지 않기로 했다.**

아이콘 영역만 `Region` 에서 빼는 방법은 Windows 10 에서는 될 가능성이 있지만(아이콘이 자식
HWND 다) Windows 11 은 XAML 이라 불확실해서 접었다. 자리를 옮기는 쪽이 두 버전에서 똑같이 돈다.

**함께 고친 것**: 비율 유지(전에는 늘려 그려 일그러졌다), 드래곤보다 아래에 그리기,
세로로 선 작업표시줄에서는 그리지 않기.

## 2. ~~캐릭터 크기를 키워도 사거리·판정 범위가 그대로다~~ — 고쳤다 (2026-11-17)

[이슈 #78](https://github.com/1rkdwnsgh1/dragon-tower/issues/78). 아래 방식으로 고쳤다.

- **몸 반지름**(드래곤·몬스터)과 **몬스터 공격 사거리·예고 범위**는 크기를 **항상** 따라간다
- **스킬 판정 반경**은 `scale_with_size=yes` 를 적은 스킬만 따라간다 (지금 5개)
- **스킬 사거리는 따라가지 않는다** — 1000% 에서 10배가 되면 균형이 깨진다

**왜 사거리를 빼고 몸 반지름을 넣었나.** 어색함의 정체는 사거리가 아니라 **몸이 겹쳐 보이는데
안 맞는 것**이었다. 판정식이 전부 `거리 <= 스킬반경 + 적반경` 꼴이라 **적 몸 반지름만 키우면
"겹치면 맞는다"가 저절로 성립**한다. 사거리를 그대로 두어 균형은 지켰다.

**남은 것**: 아주 큰 배율에서 광역 스킬이 과한지 사람이 봐야 한다. 상한(예: 2배)이 필요하면
`World::skillRadius` 한 곳만 고치면 된다.

## 3. 스킬 효과가 너무 진하다 — 투명도를 올려야 한다

**보이는 것.** 효과 그림이 본체를 덮어 드래곤이 잘 안 보인다.
(`fx_front=yes` 인 스킬에서 특히.)

**어디.** `src/win/Renderer.cpp` 의 `drawFxSheet` — `drawSheetFrame(..., alpha)` 로
넘기는 투명도와 `fxPhaseLook` 의 단계별 값.

**왜 아직 안 고쳤나.** 지금은 투명도가 **코드에 박혀 있다.** 스킬마다 다르게 주려면
`dragon.txt` 에 `fx_alpha=` 같은 설정을 더해야 하고, 그러면 기존 `fx_*` 설정과 함께
[사용법 문서](../assets/dragons/README.md)도 고쳐야 한다. 전역으로 한 번에 낮출지,
스킬마다 조절할 수 있게 할지 정해야 한다.

**관련.** 효과가 본체를 덮는 문제는 `fx_scale` 로도 다뤘다 — 망령룡 발톱을 `1.0 -> 0.7`,
그림자룡도 `0.7` 로 시작했다. 투명도는 그와 별개로 **겹쳐도 본체가 비쳐 보이게** 하는 수단이다.
