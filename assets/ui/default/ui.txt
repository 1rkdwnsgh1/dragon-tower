; 기본 UI 스킨 — 창틀·버튼·토글·막대 그림과 9조각 여백
;
; 9조각(nine-slice): 그림의 네 모서리는 그대로 두고 가장자리와 가운데만 늘려서
; 아무 크기에나 맞춘다. left/top/right/bottom 은 "늘리지 않을 테두리 두께"(픽셀,
; 원본 그림 기준)다. 장식이 큰 그림일수록 크게 잡아야 모서리가 찌그러지지 않는다.
;
; [조각이름] 아래에 여백을 적는다. 적지 않은 조각은 늘리지 않고 그대로 그린다.

[panel]
left=120
top=150
right=120
bottom=130

left=70
top=40
right=70
bottom=40

left=80
top=50
right=80
bottom=50
