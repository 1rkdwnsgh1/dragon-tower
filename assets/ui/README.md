# UI 스킨 사용법

창틀·버튼·토글·체력 막대 그림을 폴더 하나로 묶은 것이 **스킨**이다.
`assets/ui/<스킨키>/` 안에 PNG와 `ui.txt`를 둔다.

```
assets/ui/
  default/      ← 기본 스킨. 어떤 조각이 없으면 여기서 찾는다
    ui.txt
    panel.png  button.png  button_hover.png  ...
  revenant/     ← 드래곤 전용 스킨(원하는 조각만 넣으면 된다)
```

## 드래곤마다 다른 스킨 쓰기

`assets/dragons/<키>/dragon.txt` 의 `[dragon]` 구역에 한 줄 적는다.

```
ui_skin=revenant
```

**없는 조각은 자동으로 `default` 에서 가져온다.** 그래서 바꾸고 싶은 조각만 넣으면 된다.
예를 들어 체력 막대만 바꾸려면 `assets/ui/revenant/bar_fill_hp.png` 하나만 두면 된다.
`ui_skin` 을 적지 않으면 `default` 를 쓴다.

## 조각 이름

| 이름 | 쓰이는 곳 |
|---|---|
| `panel` | 창 배경(상태창·메뉴·모달) |
| `button` / `button_hover` / `button_off` | 보통 버튼의 세 가지 상태 |
| `pill` / `pill_hover` / `pill_off` | 좁은 자리의 작은 버튼 |
| `toggle_on` / `toggle_off` / `toggle_disabled` | 토글 스위치 |
| `bar_frame` | 막대 틀(빈 막대) |
| `bar_fill_hp` | 체력(초록) |
| `bar_fill_low` | 체력이 적을 때(빨강) |
| `bar_fill_exp` | 경험치(하늘) |
| `bar_fill_auto` | 자동 경험치(금색) |
| `panel_small` | 작은 창(상태창·메뉴)용 얇은 프레임. **아직 그림이 없다** |
| `square` / `square_off` | 아이콘용 작은 네모 버튼 (아직 코드에서 쓰지 않는다) |
| `check_on` | 체크 표시가 켜진 네모 (아직 코드에서 쓰지 않는다) |
| `icon_*` | 아이콘 (아직 코드에서 쓰지 않는다) |

**조각이 하나도 없어도 게임은 돈다.** 그림이 없으면 예전처럼 도형으로 그린다.

## ui.txt — 맞춤 방식과 여백

**조각마다 목적지에 맞추는 방법이 다르다.** `fit` 으로 정한다.

| fit | 하는 일 | 쓰는 곳 |
|---|---|---|
| `nine` (기본) | 9조각. 네 모서리를 지키고 가장자리·가운데만 늘린다 | 큰 창틀 |
| `height` | 높이를 목적지에 맞춰 통째로 줄이고 **가로만** 늘린다 | 버튼, 막대 |
| `contain` | 비율을 지킨 채 목적지 안에 넣는다 | 토글, 체크 |

```
[button]
fit=height
left=70
right=70
```

`left/top/right/bottom` 은 **늘리지 않을 테두리 두께**(원본 그림 기준 픽셀)다.
`height` 에서는 `left/right` 만 쓰인다.

### 큰 그림을 작은 창에 넣으면

`nine` 은 테두리가 목적지의 **35%** 를 넘지 않도록 가로·세로 같은 배율로 줄인다.
그래도 많이 줄여야 하면(원본의 55% 미만) **그림을 쓰지 않고 도형으로 그린다.**

v0.9에서 1109×1382짜리 큰 창틀을 270px 상태창에 넣었더니 테두리(240×280)가 가운데를
다 먹어서 장식만 남고 글자가 뼈 장식 위에 올라갔다. 그래서 생긴 규칙이다.

**여백 숫자만 키워서는 이 문제가 해결되지 않는다.** 작은 창에는 작은 창용 그림이 필요하다.
얇은 프레임이 생기면 `panel_small.png` 로 넣으면 된다.

### 글자가 장식에 가릴 때

버튼 글자는 테두리 **안쪽**에만 놓인다. 그래도 가리면 그 조각의 `left/right` 를 키운다
(장식이 실제로 어디까지 이어지는지 원본을 확대해 보고 정한다).

### 막대

틀을 먼저 그리고, 채움은 **틀 안쪽에 꽉 찬 길이로 그린 뒤 보이는 만큼만 잘라서** 보여 준다.
값마다 텍스처를 짧게 눌러 그리면 무늬와 양끝 장식이 찌그러지기 때문이다.
지금 `bar_frame.png` 는 안쪽이 불투명해서 틀을 먼저 그린다. 안쪽이 비치는 틀로 바꾸면
틀을 채움 **위에** 그리도록 코드를 바꿔야 한다.

## 그림 바꾸기

원본 시트에서 조각을 자를 때는 [tools/slice_ui.py](../../tools/slice_ui.py)를 쓴다.
자른 좌표가 스크립트 안에 표로 남아 있어서 같은 원본에서 다시 자를 수 있다.

```
python tools/slice_ui.py --out assets/ui/default --panels 버튼시트.png --bars 막대시트.png
```

## 한 파일에 여러 요소가 들어 있으면 안 된다

`title.png` 는 가로로 버튼 상태 3개가 한 장에 들어 있어서 스킨 폴더에서 뺐다
(`assets/references/ui/work-2026-11-14/05_title_3상태_미분리.png` 에 보관).
**조각 하나는 역할 하나여야 한다.** 상태별로 잘라서 다시 넣는다.

## 원본 보관
