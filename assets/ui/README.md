# UI 스킨 사용법

창틀·버튼·토글·체력 막대 그림을 폴더 하나로 묶은 것이 **스킨**이다.
`assets/ui/<스킨키>/` 안에 PNG와 `ui.txt`를 둔다.

```
assets/ui/
  default/      ← 기본 스킨. 어떤 조각이 없으면 여기서 찾는다
    ui.txt
    panel.png  button.png  button_hover.png  ...
  revenant/     ← 드래곤 전용 스킨(원하는 조각만 넣으면 된다)
```

## 드래곤마다 다른 스킨 쓰기

`assets/dragons/<키>/dragon.txt` 의 `[dragon]` 구역에 한 줄 적는다.

```
ui_skin=revenant
```

**없는 조각은 자동으로 `default` 에서 가져온다.** 그림뿐 아니라 **`ui.txt` 의 여백·`fit` 설정도 물려받는다.**
그래서 색만 바꾼 스킨은 PNG만 넣으면 되고 `ui.txt` 를 다시 쓸 필요가 없다. 그래서 바꾸고 싶은 조각만 넣으면 된다.
예를 들어 체력 막대만 바꾸려면 `assets/ui/revenant/bar_fill_hp.png` 하나만 두면 된다.
`ui_skin` 을 적지 않으면 `default` 를 쓴다.

## 조각 이름

| 이름 | 쓰이는 곳 |
|---|---|
| `panel` | 창 배경(상태창·메뉴·모달) |
| `button` / `button_hover` / `button_off` | 보통 버튼의 세 가지 상태 |
| `pill` / `pill_hover` / `pill_off` | 좁은 자리의 작은 버튼 |
| `toggle_on` / `toggle_off` / `toggle_disabled` | 토글 스위치 |
| `bar_frame` | 막대 틀(빈 막대) |
| `bar_fill_hp` | 체력(초록) |
| `bar_fill_low` | 체력이 적을 때(빨강) |
| `bar_fill_exp` | 경험치(하늘) |
| `bar_fill_auto` | 자동 경험치(금색) |
| `panel_small` | 작은 창(상태창·메뉴)용 얇은 프레임. **아직 그림이 없다** |
| `square` / `square_off` | 아이콘용 작은 네모 버튼 (아직 코드에서 쓰지 않는다) |
| `check_on` | 체크 표시가 켜진 네모 (아직 코드에서 쓰지 않는다) |
| `icon_*` | 아이콘 (아직 코드에서 쓰지 않는다) |

**조각이 하나도 없어도 게임은 돈다.** 그림이 없으면 예전처럼 도형으로 그린다.

## ui.txt — 맞춤 방식과 여백

**조각마다 목적지에 맞추는 방법이 다르다.** `fit` 으로 정한다.

| fit | 하는 일 | 쓰는 곳 |
|---|---|---|
| `nine` (기본) | 9조각. 네 모서리를 지키고 가장자리·가운데만 늘린다 | 큰 창틀 |
| `height` | 높이를 목적지에 맞춰 통째로 줄이고 **가로만** 늘린다 | 버튼, 막대 |
| `contain` | 비율을 지킨 채 목적지 안에 넣는다 | 토글, 체크 |

```
[button]
fit=height
left=70
right=70
```

`left/top/right/bottom` 은 **늘리지 않을 테두리 두께**(원본 그림 기준 픽셀)다.
`height` 에서는 `left/right` 만 쓰인다.

### 큰 그림을 작은 창에 넣으면

`nine` 은 테두리가 목적지의 **35%** 를 넘지 않도록 가로·세로 같은 배율로 줄인다.
그래도 많이 줄여야 하면(원본의 55% 미만) **그림을 쓰지 않고 도형으로 그린다.**

v0.9에서 1109×1382짜리 큰 창틀을 270px 상태창에 넣었더니 테두리(240×280)가 가운데를
다 먹어서 장식만 남고 글자가 뼈 장식 위에 올라갔다. 그래서 생긴 규칙이다.

**여백 숫자만 키워서는 이 문제가 해결되지 않는다.** 작은 창에는 작은 창용 그림이 필요하다.
얇은 프레임이 생기면 `panel_small.png` 로 넣으면 된다.

### 글자가 장식에 가릴 때

버튼 글자는 테두리 **안쪽**에만 놓인다. 그래도 가리면 그 조각의 `left/right` 를 키운다
(장식이 실제로 어디까지 이어지는지 원본을 확대해 보고 정한다).

### 막대

틀을 먼저 그리고, 채움은 **틀 안쪽에 꽉 찬 길이로 그린 뒤 보이는 만큼만 잘라서** 보여 준다.
값마다 텍스처를 짧게 눌러 그리면 무늬와 양끝 장식이 찌그러지기 때문이다.
지금 `bar_frame.png` 는 안쪽이 불투명해서 틀을 먼저 그린다. 안쪽이 비치는 틀로 바꾸면
틀을 채움 **위에** 그리도록 코드를 바꿔야 한다.

## 그림 바꾸기

원본 시트에서 조각을 자를 때는 [tools/slice_ui.py](../../tools/slice_ui.py)를 쓴다.
자른 좌표가 스크립트 안에 표로 남아 있어서 같은 원본에서 다시 자를 수 있다.

```
python tools/slice_ui.py --out assets/ui/default --panels 버튼시트.png --bars 막대시트.png
```

## 색만 바꾼 스킨 만들기

[tools/tint_ui.py](../../tools/tint_ui.py) 로 기본 스킨의 색상만 돌려 새 스킨을 만든다.
모양·명암·발광은 그대로 두고 **색상(hue)만** 돌리며, 회색(금속 테두리)은 건드리지 않는다.

```
python tools/tint_ui.py --out assets/ui/shadow --hue -75
```

체력 초록·경험치 파랑처럼 **색이 의미를 가지는 조각은 기본으로 제외**한다. 색을 바꾸면
"체력이 적다"는 신호가 흐려지기 때문이다. 넣고 싶으면 `--pieces` 에 직접 적는다.

실제 예: `assets/ui/shadow/` (그림자룡 전용, 청록 → 보라).

## 한 파일에 여러 요소가 들어 있으면 안 된다

`title.png` 는 가로로 버튼 상태 3개가 한 장에 들어 있어서 스킨 폴더에서 뺐다
(`assets/references/ui/work-2026-11-14/05_title_3상태_미분리.png` 에 보관).
**조각 하나는 역할 하나여야 한다.** 상태별로 잘라서 다시 넣는다.

## 원본 보관

자른 원본 시트는 [assets/references/ui/](../references/ui/)에 날짜 폴더로 둔다.
조각을 다시 자르거나 여백을 고칠 때 필요하다.

## `taskbar.png` — 작업표시줄 꾸미기 (v1.9)

스킨 폴더에 `taskbar.png` 를 두면, 그 스킨을 쓰는 드래곤을 선택했을 때 **윈도우 작업표시줄
바로 바깥쪽에** 그 띠가 그려진다. 없으면 아무 일도 일어나지 않는다(없는 게 정상이다).

- 가로로 길고 세로가 얇은 그림을 쓴다. 예: `assets/ui/revenant/taskbar.png` 는 3840×90.
- **비율을 지켜서** 그린다(2026-11-17, #77). 가로를 띠 너비에 맞추고 세로가 넘치면 가운데를 잘라
  쓴다. 납작하면 작업표시줄에 붙는 쪽으로 맞춘다. 9분할·`fit` 설정은 쓰지 않는다.
- 좌우 끝은 흐리게 빼 두는 편이 자연스럽다. 해상도가 달라도 잘린 티가 덜 난다.
- **작업표시줄을 덮지 않는다.** 띠는 작업표시줄 바로 위(작업표시줄이 화면 위쪽에 붙어 있으면
  바로 아래)에 작업표시줄과 같은 높이로 그려진다. 시작 단추·아이콘·트레이·시계를 가리지 않는다.
- 클릭은 항상 통과한다. 드래곤보다 **아래**에 그려져 드래곤을 덮지 않는다.
- 세로로 선 작업표시줄(왼쪽·오른쪽 고정)에서는 그리지 않는다 — 가로로 긴 띠가 맞지 않는다.


## 탑 선택창

기본 스킨에는 검수한 Atmospheric 탑 그림·카드 3종·선택 테두리·입장 버튼이 포함된다. 드래곤 스킨에 같은 이름의 파일이 있으면 해당 파일을 우선한다.

아래 PNG를 `assets/ui/default/` 또는 드래곤이 쓰는 `assets/ui/<스킨>/`에 둔다. 대표 이미지는 비율을 유지한 채 가운데를 잘라 배치한다. 레벨·이름·보상 등의 문구는 게임이 그린다.

| 파일 | 권장 픽셀 | 대체 그림 |
|---|---:|---|
| `tower_illustration.png` | 400 × 1024 | 밤의 석탑 도형 |
| `tower_card_normal.png`, `tower_card_mid.png`, `tower_card_field.png` | 1050 × 128 | 층 유형 색과 적 스프라이트 |
| `tower_floor_<층번호>.png` | 584 × 310 | 해당 층 대표 적 |
| `tower_portrait_<종키>.png` | 260 × 236 | 대기 모션 첫 프레임 |
| `tower_skill_<종키>_<스킬번호>.png` | 108 × 102 | 기술 효과 프레임 또는 슬롯 번호 |
| `tower_selection.png`, `tower_enter.png` | 1050 × 128 / 508 × 124 | 금색 선택 테두리 / 보라색 버튼 |

스킬 번호는 `dragon.txt`의 `skill.N`과 같은 1부터 시작한다. 선택 테두리는 투명 중앙을 권장한다.

탑 그림은 목록과 함께 세로로 이동한다. 높은 층으로 가면 그림의 위쪽이 보이고, 1층 쪽에서는 아래쪽이 보인다. 전체 그림의 상단과 하단을 각각 탑 꼭대기와 바닥으로 구성하면 교체 즉시 같은 동작이 적용된다.
