# DRAGON TOWER — 스킬 아이콘 공통 적용 안내 V1

## 패키지 구성
- `REVENANT/ORIGINAL/`, `SHADOW/ORIGINAL/`: 각각 7장의 **무수정 원본 PNG** (총 14장)
- `REVENANT/ICON_256/`, `SHADOW/ICON_256/`: 각 원본을 **가로세로 비율을 유지하여 256×256으로 축소**한 편의용 PNG (총 14장)
- `ICON_MANIFEST.csv`: 파일명, 임시 스킬명, 원본 파일과 SHA-256 매핑
- `REVENANT/REVENANT_ICON_GUIDE.md`, `SHADOW/SHADOW_ICON_GUIDE.md`: 각 드래곤 적용 문서

## 실제 파일 검사 결과
원본 14장 모두 **1254×1254, RGB 모드**이며 실제 알파 채널이 없습니다. 따라서 검정 계열 배경과 장식 프레임은 **이미지에 포함된 픽셀**입니다. `ICON_256` 역시 RGB이며 투명 PNG가 아닙니다. 투명 배경이 필요한 UI라면 별도의 정밀 분리·검수 작업이 필요합니다.

## 적용 절차
1. `ICON_MANIFEST.csv`에서 스킬과 파일을 매핑합니다. 그림자 드래곤 스킬명은 **임시 이름**이므로 실제 기획/코드의 스킬 ID를 우선합니다.
2. 스킬 슬롯마다 **개별 아이콘 PNG 한 장만** 사용합니다. 이미지 전체를 패널 배경이나 게이지로 늘려 붙이지 않습니다.
3. 48×48 또는 64×64 등의 슬롯에 이미지를 **정사각 비율 유지**로 축소합니다. 원본을 변형해 가로세로를 늘이지 않습니다.
4. 아이콘에는 뼈 장식 테두리가 포함되어 있습니다. 게임 UI 프레임을 별도로 쓰는 경우 테두리 중복이 발생할 수 있으므로 **기존 슬롯 프레임 제거** 또는 **아이콘 내부 그림만 크롭한 별도 버전 제작** 중 하나를 택합니다.
5. 버튼의 클릭 영역과 레이아웃은 기존 코드를 유지합니다. 선택, 쿨타임, 비활성, 잠금 상태는 **이미지 위에 별도 레이어**로 표시합니다.
6. 스킬 구현 여부와 아이콘 존재 여부를 혼동하지 않습니다. 미구현 스킬은 비활성 상태로 보여줍니다.
7. 게임 내에서 HUD 배율, 작은 크기(32~64px), 자동/수동 전환, 툴팁 및 스킬별 배치가 올바른지 검수합니다.

## 주의
이번 ZIP은 **스킬 아이콘 에셋과 사용 설명서**이며, 게임 코드·GitHub 수정이나 스킬 기능 구현을 포함하지 않습니다. 기본 전투 시스템과 기존 개발 순서는 GitHub 최신 계획에 맞춰 별도 검증해야 합니다.
