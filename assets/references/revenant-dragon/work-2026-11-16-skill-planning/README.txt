망령룡 추가 스킬 1컷 시각 기획 자료 (2026-11-16 보관)
=====================================================

내용
  스킬 추가 기획 1컷 이미지 1.png ~ 7.png
      1컷 콘셉트 시트 7장. 1~4차와 7차는 4열x2행(8컷), 5~6차는 5열x2행(10컷). 합계 60컷.
  스킬 추가 기획 1컷 이미지 1 프롬프트.txt ~ 7 프롬프트.txt
      각 시트를 만들 때 쓴 프롬프트 원문. 패널 순서는 이미지와 같다.
  manifest.json
      파일별 크기, SHA-256, 화소 해시, PC 원본과의 일치 여부, 인계 ZIP 사본과의 비교.
  SKILL_INVENTORY.csv
      60종 목록(세트, 패널, 한국어명, 영문 가칭, 선호 상태, 메모).

상태
  기획 참고 자료다. 제작 승인도, 스킬 채택도, 게임 적용도 아니다.
  1컷 시트이므로 투명 배경 게임 에셋이나 애니메이션 프레임이 아니다.
  설명과 선호 기록은 docs/characters/revenant-dragon-skill-concepts.md 에 있다.

출처
  사용자 PC: 드래곤 타워/gpt 작업용 레퍼런스/망령용/스킬 추가 기획
  PC 원본 14개는 확장자가 없었다. 내용은 그대로 두고 이미지에 .png, 프롬프트에 .txt만 붙였다.

받을 때
  PNG는 Git LFS로 관리한다. git lfs pull 로 실제 파일을 내려받는다.
