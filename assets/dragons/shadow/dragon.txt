; 그림: assets/references/shadow-dragon/work-2026-11-14 의 시트를 한 번에 변환해 넣었다.
; 다섯 상태를 --set 으로 함께 변환해 **공통 배율**을 썼으므로 상태 사이 크기 관계가 그대로다.
; 그래서 render_scale 보정이 필요 없다(망령룡은 상태마다 다른 패키지에서 와서 보정이 필요했다).
;
; 다시 만들 때 쓴 명령:
;   python tools/make_sheet.py \
;     --set idle=dragon_attack_12_v2.png@3x4:1,1-4,3,2 \
;     --set attack=dragon_attack_12_v2.png@3x4:*,1-4 \
;     --set move=dragon_walk_art_12.png@3x4:*,1-4 \
;     --set fly=dragon_flight_12_reference_v3.png@3x4:*,1-4 \
;     --set rest=dragon_rest_relaxed_12_v3.png@3x4:*,1-4 \
;     --ref move --bg auto --bg-tol 26 --bg-shadow 58 --bg-chroma 16 --grid-inset 6 \
;     --cell 256 --ratio 0.70 -o assets/dragons/shadow
;
; --grid-inset 6 : 칸 사이 구분선이 배경색으로 잡히지 않게 안쪽으로 깎는다
; --bg-shadow 58 : 바닥 그림자(무채색)를 함께 지운다. 몸통은 더 어두워서 남는다

; idle: 전용 시트가 없어서 공격 시트의 앞쪽 4장을 1-2-3-4-3-2 로 왕복시켜 만들었다.
