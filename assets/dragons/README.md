# 드래곤 폴더 사용법 (v0.2)

드래곤 하나 = 폴더 하나입니다. 게임은 켤 때 이 폴더 안의 하위 폴더를 모두 읽어 드래곤 목록을 만듭니다.
**코드를 고치지 않아도** 이미지를 넣거나 새 드래곤을 추가할 수 있습니다.

규격의 근거와 배경은 [캐릭터 적용 기획](../../docs/character-pipeline.md)에 있습니다.

## 폴더 안에 넣는 것

| 파일 | 내용 | 없으면 |
|---|---|---|
| `dragon.txt` | 이름·능력치·스킬·재생 정보 | 내장 4종은 기본값 사용. 새 종은 등록되지 않음 |
| `idle.png` | 대기 동작 시트 | `dragon.png` → 임시 도형 |
| `move.png` | 이동 동작 시트 | `idle.png`로 대신 그림 |
| `attack.png` | 공격·스킬 동작 시트 | `idle.png`로 대신 그림 |
| `hit.png` | 피격 동작 시트 | `idle.png` + 깜빡임 효과 |
| `death.png` | 사망 동작 시트 | `idle.png` + 사라지는 효과 |
| `fly.png` | 비행 시트. 바탕화면에서 스스로 날 때 | `move.png` → 없으면 `idle.png` |
| `dragon.png` | 애니메이션 없이 쓸 정지 이미지 1장 | 시트가 있으면 쓰이지 않음 |
| `CREDITS.md` | 제작자·출처·라이선스·사용한 생성 도구 | (직접 적어 주세요) |

시트는 **가로 한 줄**, 칸 크기 **256×256**, 발이 칸의 **(128, 240)**에 오도록, **오른쪽을 보게** 만듭니다.
[그리기 템플릿](template-256.png) 위에 레이어를 얹어 그리면 크기가 맞습니다.
규격과 다르게 만든 그림은 [tools/make_sheet.py](../../tools/make_sheet.py)로 변환하세요.
**한 드래곤의 여러 상태는 반드시 `--set`으로 한 번에 변환하세요.** 따로 변환하면 상태마다 크기가 달라집니다.

```
python tools/make_sheet.py --mirror -o assets/dragons/<키> \
  --set idle=원본/대기 --set move=원본/걷기 --set fly=원본/비행
```

## 1. 기존 드래곤에 그림만 넣기

`fire`, `earth`, `wind`, `water` 폴더에 `idle.png`를 넣고 게임을 다시 켜면 바로 보입니다.
`dragon.txt`는 없어도 됩니다(능력치는 게임에 들어 있는 기본값을 씁니다).

## 2. 기존 드래곤의 수치만 바꾸기

그 폴더에 `dragon.txt`를 만들고 **바꿀 값만** 적습니다. 적지 않은 값은 기본값 그대로입니다.

```
[dragon]
hp=120
[skill.1]
cooldown=3.5
```

## 2-1. 상태마다 캐릭터 크기가 다르게 보일 때

원본 그림이 상태마다 다른 크기로 그려진 경우입니다. 그 상태의 `[anim.*]`에 `render_scale`을 적으면
그리는 단계에서 크기를 맞춥니다. 바닥 기준선은 그대로라 발 위치가 흔들리지 않습니다.

```
[anim.fly]
render_scale=1.37
```

눈대중하지 말고 상태마다 같은 신체 부위(예: 몸통 높이)를 재서 비율로 정하세요.

## 3. 새 드래곤 추가하기

1. `_example` 폴더를 복사하고, 이름을 쓸 키로 바꿉니다(예: `revenant`). `_`로 시작하면 읽지 않습니다.
2. 폴더 안 `dragon.txt`의 이름·설명·수치·스킬을 고칩니다.
3. `idle.png`를 넣고 게임을 켜서 크기와 위치를 확인합니다.
4. 나머지 상태 시트를 하나씩 추가합니다.
5. `CREDITS.md`에 출처와 라이선스를 적습니다.
6. 캐릭터 기획은 `docs/characters/<키>.md`에 둡니다.

**폴더 이름(키)은 저장 파일에 기록됩니다. 한 번 정하면 바꾸지 마세요.** 바꾸면 그 키로 저장된
개체와 도감 기록을 찾지 못합니다. 폴더를 지워도 저장 기록은 남고, 그 종은 "데이터 파일이 없는 종"으로 표시됩니다.

## 잘못 적으면 어떻게 되나요

게임을 켤 때 화면 알림으로 어느 파일 몇 행이 잘못됐는지 알려 줍니다(모르는 키, 읽을 수 없는 값,
칸 수가 맞지 않는 시트 등). 잘못된 값은 기본값이나 허용 범위로 맞춰 게임은 계속 실행됩니다.

## 이 드래곤만 다른 UI 쓰기

`[dragon]` 구역에 한 줄 적는다. 자세한 내용은 [UI 스킨 사용법](../ui/README.md)에 있다.

```
ui_skin=shadow
```

실제 예: `assets/dragons/shadow/dragon.txt` (그림자룡 → `assets/ui/shadow/`).
