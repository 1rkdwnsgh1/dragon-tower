# 드래곤 폴더 사용법 (v0.2)

드래곤 하나 = 폴더 하나입니다. 게임은 켤 때 이 폴더 안의 하위 폴더를 모두 읽어 드래곤 목록을 만듭니다.
**코드를 고치지 않아도** 이미지를 넣거나 새 드래곤을 추가할 수 있습니다.

규격의 근거와 배경은 [캐릭터 적용 기획](../../docs/character-pipeline.md)에 있습니다.

## 폴더 안에 넣는 것

| 파일 | 내용 | 없으면 |
|---|---|---|
| `dragon.txt` | 이름·능력치·스킬·재생 정보 | 내장 4종은 기본값 사용. 새 종은 등록되지 않음 |
| `idle.png` | 대기 동작 시트 | `dragon.png` → 임시 도형 |
| `move.png` | 이동 동작 시트 | `idle.png`로 대신 그림 |
| `attack.png` | 공격·스킬 동작 시트 | `idle.png`로 대신 그림 |
| `hit.png` | 피격 동작 시트 | `idle.png` + 깜빡임 효과 |
| `death.png` | 사망 동작 시트 | `idle.png` + 사라지는 효과 |
| `fly.png` | 비행 시트. 바탕화면에서 스스로 날 때 | `move.png` → 없으면 `idle.png` |
| `dragon.png` | 애니메이션 없이 쓸 정지 이미지 1장 | 시트가 있으면 쓰이지 않음 |
| `CREDITS.md` | 제작자·출처·라이선스·사용한 생성 도구 | (직접 적어 주세요) |

시트는 **가로 한 줄**, 칸 크기 **256×256**, 발이 칸의 **(128, 240)**에 오도록, **오른쪽을 보게** 만듭니다.
[그리기 템플릿](template-256.png) 위에 레이어를 얹어 그리면 크기가 맞습니다.
규격과 다르게 만든 그림은 [tools/make_sheet.py](../../tools/make_sheet.py)로 변환하세요.
**한 드래곤의 여러 상태는 반드시 `--set`으로 한 번에 변환하세요.** 따로 변환하면 상태마다 크기가 달라집니다.

```
python tools/make_sheet.py --mirror -o assets/dragons/<키> \
  --set idle=원본/대기 --set move=원본/걷기 --set fly=원본/비행
```

## 1. 기존 드래곤에 그림만 넣기

`fire`, `earth`, `wind`, `water` 폴더에 `idle.png`를 넣고 게임을 다시 켜면 바로 보입니다.
`dragon.txt`는 없어도 됩니다(능력치는 게임에 들어 있는 기본값을 씁니다).

## 2. 기존 드래곤의 수치만 바꾸기

그 폴더에 `dragon.txt`를 만들고 **바꿀 값만** 적습니다. 적지 않은 값은 기본값 그대로입니다.

```
[dragon]
hp=120
[skill.1]
cooldown=3.5
```

## 2-1. 상태마다 캐릭터 크기가 다르게 보일 때

원본 그림이 상태마다 다른 크기로 그려진 경우입니다. 그 상태의 `[anim.*]`에 `render_scale`을 적으면
그리는 단계에서 크기를 맞춥니다. 바닥 기준선은 그대로라 발 위치가 흔들리지 않습니다.

```
[anim.fly]
render_scale=1.37
```

눈대중하지 말고 상태마다 같은 신체 부위(예: 몸통 높이)를 재서 비율로 정하세요.

## 2-2. 스킬 추가하기 (v1.4)

`[skill.1]`부터 차례로 적은 만큼 스킬이 늘어납니다. 개수 제한은 없습니다(최고 레벨까지).

```
[skill.4]
name=어둠의 숨결
desc=앞쪽으로 어둠을 토해 지나가는 적을 모두 태운다.
kind=Line
power=2.4
range=300
radius=44
cooldown=11
motion=breath          ; skill_breath.png 를 재생한다. 없으면 공용 attack 으로 그려진다
motion_fps=12
motion_frame_w=256
motion_render_scale=1.0
```

**해제 레벨(`level=`)은 적지 않아도 됩니다.** 적지 않으면 *아직 아무 스킬도 쓰지 않은 가장 낮은
레벨*이 목록 순서대로 하나씩 배정됩니다 — **한 레벨에 한 스킬**입니다. 특정 스킬만 늦게 주고
싶을 때만 `level=`을 적으세요. 섞어 써도 됩니다(적은 쪽이 먼저 자리를 잡습니다).

`kind=`는 액티브 8종(`Projectile` `Burst` `Line` `Dash` `Heal` `Shield` `Haste` `Zone`)과
패시브 2종입니다.

| 패시브 | 하는 일 | 쓰는 값 |
|---|---|---|
| `PassiveStat` | 능력치를 상시 올린다 | `stat=` (hp/atk/def/speed/dodge/regen), `power=` |
| `PassiveOnKill` | 적을 쓰러뜨릴 때 최대 체력의 `power` 비율만큼 회복 | `power=` |

`PassiveStat`의 `power`는 hp/atk/def/speed에서는 **비율**(0.1 = +10%), dodge/regen에서는
**더하는 값**입니다. 회피는 상한 0.75를 넘지 못합니다.

**액티브는 스킬 관리창에서 4개를 골라 장착해야 쓸 수 있습니다**(조작키 1~4, 자동 전투도 같습니다).
**패시브는 장착하지 않습니다** — 레벨로 해제되면 항상 적용됩니다.

## 2-3. 스킬 효과(FX) 그림 넣기 (v1.6)

`motion=`이 **드래곤 본체**의 움직임이라면, `fx=`는 **본체와 따로 그리는 효과 그림**입니다
(터지는 빛, 번지는 안개 같은 것). 지금까지는 효과를 도형으로만 그렸습니다.

```
[skill.4]
name=어둠의 숨결
kind=Line
motion=breath          ; 본체 모션 — skill_breath.png
fx=breath_wave         ; 효과 그림 — fx_breath_wave.png
fx_front=yes           ; yes면 본체 위, no면 본체 뒤에 그린다 (기본 yes)
fx_scale=1.4           ; 효과 크기 배율 (기본 1.0, 0.1~8.0)
fx_offset_x=130        ; 본체 기준 가로 보정. 바라보는 쪽이 양수 (100% 기준 px)
fx_offset_y=-24        ; 본체 기준 세로 보정. 위로 올리려면 음수 (100% 기준 px)
fx_windup=0.12         ; 발동 — 터지기 직전 (적지 않으면 0.12초)
fx_hold=0.25           ; 지속 — 온전히 보이는 동안 (0.25초)
fx_tail=0.18           ; 잔류 — 옅어지며 사라짐 (0.18초)
fx_fps=12
fx_frame_w=256
fx_render_scale=1.0
```

**`fx=`를 적지 않으면 지금까지와 똑같습니다** — 도형 효과가 그대로 나옵니다. 그림이 준비된 스킬만
하나씩 옮기면 됩니다. `fx=`를 적었는데 `fx_<이름>.png` 가 없으면 역시 도형으로 그려집니다
(깨진 그림이 나오지 않습니다).

효과는 **발동 → 지속 → 잔류** 세 단계를 지납니다. 세 값을 적지 않으면 기본값(합 0.55초)을 쓰고,
적으면 그 합이 효과의 전체 길이가 됩니다. 기본값은
[`include/core/Config.h`](../../include/core/Config.h) 의 `cfg::kFxWindup` 등에 있습니다.

**그림이 어떻게 보이는가** (큐 8번에서 정했습니다)

- **시트 모양**은 본체 시트와 같습니다 — 가로 한 줄, `fx_frame_w=` 가 칸 너비(적지 않으면 정사각).
  `fx_fps=` 로 넘깁니다. 너비가 칸 너비로 나누어떨어지지 않으면 경고가 남고 도형으로 그려집니다.
- **크기 기준은 드래곤 본체입니다.** `fx_scale=1.0` 이면 효과가 **본체와 같은 높이**로 그려지고,
  `fx_render_scale=` 을 한 번 더 곱합니다. (본체 높이는 보기 크기 설정을 따라갑니다.)
  `fx_offset_x`·`fx_offset_y` 도 같은 배율로 커집니다 — 그래서 100% 기준으로 적습니다.
- **위치**는 효과가 터진 지점이고, `fx_offset_x=`·`fx_offset_y=` 만큼 옮깁니다
  (가로는 바라보는 쪽이 양수, 세로는 위가 음수).
- **보정값은 "100% 기준 px" 입니다.** 보기 크기 설정(50%~1000%)을 곱해서 씁니다 — 100% 에서
  머리 위였던 효과가 1000% 에서도 머리 위입니다. (2026-11-16 에 뜻이 바뀌었습니다. 그 전에는
  화면 px 였고, 큰 배율에서 보정이 몸통에 파묻혔습니다.)
- **좌우를 뒤집습니다.** 효과가 왼쪽으로 나가면 그림도 좌우로 뒤집히고 `fx_offset_x` 의 방향도
  같이 뒤집힙니다. 방향은 드래곤이 보는 쪽이 아니라 **효과가 뻗어 나가는 쪽**(발동점 → 끝점)
  으로 판정합니다. `Burst` 처럼 터지는 지점과 끝점이 같은 효과는 뒤집지 않습니다.
- **세 단계가 이렇게 보입니다**: 발동은 0.55배에서 1배로 커지며 또렷해지고, 지속은 1배로 그대로,
  잔류는 1.18배로 조금 퍼지며 옅어집니다. 길이는 `fx_windup`·`fx_hold`·`fx_tail` 로 조절합니다.
- `Zone`(장판)과 `Projectile`(발사체)은 **아직 `fx=` 를 쓰지 않습니다** — 각자 그려집니다.
  지속이 긴 장판에 세 단계를 억지로 맞추지 않기로 했습니다(`docs/implementation-notes.md` 참고).
해제됐는데 빈 칸이 있으면 자동으로 들어갑니다. 쓰고 싶지 않은 스킬은 다른 스킬로 덮어쓰세요.

제대로 들어갔는지는 `asset_check`로 확인할 수 있습니다. 스킬별 해제 레벨과 모션 파일 유무를 적어 줍니다.

```
./build/asset_check assets
```

## 3. 새 드래곤 추가하기

1. `_example` 폴더를 복사하고, 이름을 쓸 키로 바꿉니다(예: `revenant`). `_`로 시작하면 읽지 않습니다.
2. 폴더 안 `dragon.txt`의 이름·설명·수치·스킬을 고칩니다.
3. `idle.png`를 넣고 게임을 켜서 크기와 위치를 확인합니다.
4. 나머지 상태 시트를 하나씩 추가합니다.
5. `CREDITS.md`에 출처와 라이선스를 적습니다.
6. 캐릭터 기획은 `docs/characters/<키>.md`에 둡니다.

**폴더 이름(키)은 저장 파일에 기록됩니다. 한 번 정하면 바꾸지 마세요.** 바꾸면 그 키로 저장된
개체와 도감 기록을 찾지 못합니다. 폴더를 지워도 저장 기록은 남고, 그 종은 "데이터 파일이 없는 종"으로 표시됩니다.

## 잘못 적으면 어떻게 되나요

게임을 켤 때 화면 알림으로 어느 파일 몇 행이 잘못됐는지 알려 줍니다(모르는 키, 읽을 수 없는 값,
칸 수가 맞지 않는 시트 등). 잘못된 값은 기본값이나 허용 범위로 맞춰 게임은 계속 실행됩니다.

## 이 드래곤만 다른 UI 쓰기

`[dragon]` 구역에 한 줄 적는다. 자세한 내용은 [UI 스킨 사용법](../ui/README.md)에 있다.

```
ui_skin=shadow
```

실제 예: `assets/dragons/shadow/dragon.txt` (그림자룡 → `assets/ui/shadow/`).

## 크기를 키우면 판정도 넓어지게 하기 (`scale_with_size`)

캐릭터 크기 설정(50%~1000%)을 올리면 **몸 반지름과 몬스터 공격 사거리는 항상 같이 커집니다.**
몸집이 커졌는데 겹쳐 보이는 적에게 공격이 안 닿는 일을 막기 위해서입니다.

**스킬 판정 반경은 켠 스킬만** 커집니다:

```
scale_with_size=yes
```

- **사거리(`range`)는 켜도 커지지 않습니다.** 1000% 에서 사거리가 10배가 되면 균형이 깨집니다.
- 켜는 기준: **광역 스킬(`Burst`·`Zone`)과 효과 그림이 넓은 스킬.** 발톱·가르기처럼
  `fx_scale` 이 작은 좁은 스킬은 켜지 않습니다 — 그림보다 판정이 커져 버립니다.
- 적지 않으면 꺼진 것으로 봅니다. 기존 스킬은 아무것도 달라지지 않습니다.


## 발사체(`Projectile`) 스킬에 효과 그림을 쓸 때

2026-11-17 부터 `Projectile` 도 효과 그림을 씁니다. **그림을 두 장 씁니다.**

```
fx=bolt                ; 날아가는 동안 발사체를 따라다닌다 (반복 재생)
fx_impact=bolt_hit     ; 맞는 순간 한 번 터진다
```

- **적지 않으면 전과 똑같이** 동그라미로 그려집니다.
- 날아가는 그림은 **반복 재생**됩니다(다른 효과는 1회 재생인 것과 다릅니다). 멈춰 보이면
  `fx_fps` 를 올리세요.
- 날아가는 그림은 **목표 쪽을 보도록 좌우가 뒤집힙니다.** 원본을 **오른쪽 지향**으로 만드세요.
- `fx_scale` 은 두 그림이 **같이** 씁니다. `fx_windup`·`fx_hold`·`fx_tail` 은 **맞는 순간**에만
  쓰입니다(날아가는 동안은 단계가 없습니다).
- `fx_offset_x`·`fx_offset_y` 는 날아가는 그림에 쓰이지 않습니다 — 발사체 위치가 기준입니다.
