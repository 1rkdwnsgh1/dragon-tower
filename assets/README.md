# 이미지 자료(assets)

## 캐릭터별 참고 자료

- [망령룡 캐릭터 기획](../docs/characters/revenant-dragon.md): 최신 외형 시트와 최초 배경 일러스트는 `references/revenant-dragon/`에 보관한다. 이 자료는 컨셉 참고용이며 아래 런타임 파일 목록에 연결된 완성 에셋이 아니다. 망령룡의 2D 제작은 해당 기획서의 외형 기준을 우선한다. 애니메이션 지원은 향후 검토 사항이다.

이 폴더에 아래 이름의 PNG를 넣으면 게임이 임시 도형 대신 그 이미지를 그립니다. 없는 파일은 계속 임시 도형으로 표시되므로 하나씩 넣어 보며 확인해도 됩니다. 게임은 시작할 때 이미지를 읽으므로 파일을 바꾼 뒤에는 게임을 다시 실행하세요.

## 공통 규칙

- 형식: PNG, **배경 투명**(알파 채널). 바탕화면 위에 그대로 떠 있으므로 배경이 있으면 네모 상자로 보입니다.
- 방향: 캐릭터는 **오른쪽을 바라보게** 그립니다. 왼쪽을 볼 때는 게임이 좌우를 뒤집습니다.
- 여백: 캐릭터 주위에 투명 여백을 조금만 둡니다. 게임이 이미지 높이를 기준으로 크기를 맞춥니다.
- 크기: 아래 권장 크기 이상이면 됩니다. 정사각형이 아니어도 비율은 유지됩니다.
- 한 장짜리 정지 이미지입니다. 게임이 위아래로 살짝 흔들어 움직임을 줍니다.

|---|---|---|---|
| `dragon_fire.png` | 화염 드래곤(공격형) | 512×512 | 약 102px |
| `dragon_earth.png` | 대지 드래곤(방어형) | 512×512 | 약 102px |
| `dragon_wind.png` | 바람 드래곤(기동형) | 512×512 | 약 102px |
| `dragon_water.png` | 물 드래곤(회복·지속형) | 512×512 | 약 102px |
| `enemy_imp.png` | 일반 적 임프 | 256×256 | 약 62px |
| `boss_guardian.png` | 보스 탑의 수호자 | 512×512 | 약 161px |
| `button_settings.png` | 설정 버튼 아이콘(원 안에 들어감) | 128×128 | 약 36px |

스킬 아이콘 이름 예: `skill_fire_1.png`(화염구), `skill_fire_2.png`(화염 폭발), `skill_fire_3.png`(불꽃 숨결). 종류는 `fire`, `earth`, `wind`, `water`, 번호는 1~3입니다.

| 종류 | 1 | 2 | 3 |
|---|---|---|---|
| fire | 화염구 | 화염 폭발 | 불꽃 숨결 |
| earth | 바위 던지기 | 대지의 방패 | 지진 |
| wind | 질풍 돌진 | 회오리 | 순풍 |

## 이미지 생성 요청 예시

여러 장의 그림체를 맞추려면 아래 **공통 문장**을 매번 앞에 붙이세요.

> 공통: 귀여운 2D 게임 캐릭터 스프라이트, 깔끔한 외곽선, 부드러운 셀 셰이딩, 측면 시점, 오른쪽을 바라봄, 전신이 모두 보임, 완전히 투명한 배경(PNG), 그림자·바닥·글자 없음, 정사각형 캔버스 가운데 배치

- `dragon_fire.png`: 공통 + "작은 아기 드래곤, 주황빛 붉은 비늘, 꼬리 끝에 작은 불꽃, 날개를 살짝 편 자세, 공격적이지만 귀여운 표정"
- `dragon_earth.png`: 공통 + "작은 아기 드래곤, 갈색과 이끼색 비늘, 등에 바위 같은 돌기, 통통하고 단단한 체형, 듬직한 표정"
- `dragon_wind.png`: 공통 + "작은 아기 드래곤, 민트색 비늘, 길고 가는 몸과 큰 날개, 몸 주변에 바람 줄기, 날렵한 표정"
- `dragon_water.png`: 공통 + "작은 아기 드래곤, 푸른 비늘, 지느러미 모양 날개와 귀, 몸에 물방울 무늬, 온화한 표정"
- `enemy_imp.png`: 공통 + "작은 보라색 임프 몬스터, 둥근 몸, 작은 뿔 두 개, 노란 눈, 장난스럽고 약간 심술궂은 표정"
- `boss_guardian.png`: 공통 + "탑을 지키는 거대한 석조 수호자 보스, 짙은 붉은 갑옷, 금색 왕관 장식, 빛나는 노란 눈, 위압적인 모습"
- `button_settings.png`: "단순한 톱니바퀴 아이콘, 흰색, 평면 디자인, 완전히 투명한 배경(PNG), 글자 없음"
- 스킬 아이콘: "게임 스킬 아이콘, <스킬 설명>, 정사각형, 선명한 색, 단순한 형태, 글자 없음" (예: "불덩이가 날아가는 모습")

투명 배경이 아닌 이미지가 나오면 "배경을 완전히 투명하게 다시 만들어 줘"라고 요청하거나, 배경 제거 도구로 지운 뒤 넣으세요.
