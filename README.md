# Dragon Tower (가제)

드래곤을 육성하고 탑에 도전하는 싱글 플레이 게임의 기획 및 초기 프로젝트입니다. 현재 문서는 검증할 가정을 포함하며, Windows와 Godot 4를 대상으로 하며 플레이 가능한 게임은 아직 없습니다.

- [통합 기획서](docs/game-design.md)
- [개발 로드맵과 체크포인트](docs/roadmap.md)
- `game/`: Godot 4 프로젝트와 시작 장면
- `assets/`: 직접 제작하거나 사용 권한이 확인된 리소스
- `tests/`: 핵심 규칙 검증 자료

## 첫 시작
1. 기획서의 미결정 사항을 확인하고 Windows와 Godot 4를 기준으로 바탕화면 구현 방식을 결정합니다.
2. 로드맵의 1단계에서 한 드래곤과 한 적의 수동 전투를 작은 화면으로 시험합니다.
3. 각 체크포인트를 직접 확인한 뒤 다음 단계로 진행합니다.

개발은 완성 코드를 한꺼번에 추가하기보다 방향과 체크포인트를 나누어 진행합니다.
