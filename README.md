# Dragon Tower (가제)

Windows 바탕화면에서 드래곤을 육성하고 탑에 도전하는 게임입니다. 주 언어는 C++이며 게임 엔진은 사용하지 않습니다. 아직 플레이 가능한 게임은 아닙니다.

- [통합 기획서](docs/game-design.md)
- [개발 로드맵과 체크포인트](docs/roadmap.md)
- `src/`: 게임과 플랫폼 구현 코드
- `include/`: 공유 헤더
- `assets/`: 사용 이미지·음향 등
- `tests/`: 핵심 규칙 검증 자료

## 개발 환경

Windows와 C++17을 기준으로 합니다. 빌드 구성에는 CMake를 사용합니다. 그래픽·입력·음향 라이브러리는 아직 결정하지 않았습니다. 필요한 창 기능은 Windows API를 검토합니다.

CMake와 C++ 컴파일러를 설치한 후 프로젝트 폴더에서 다음 명령으로 시작 파일을 빌드할 수 있습니다.

```powershell
cmake -S . -B build
cmake --build build
```

현재 실행 파일은 개발 환경을 확인하는 최소 시작점입니다. 바탕화면 표시나 전투는 아직 구현되지 않았습니다. 개발은 방향과 체크포인트를 나누어 진행합니다.
